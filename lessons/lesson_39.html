Phase 1
Absolute vs Relative Units
💡 Concept

Absolute units: px (most common), pt (print), cm/mm (rare). Relative units: em (relative to parent font-size), rem (relative to root html font-size — consistent!), % (relative to parent dimension), vw/vh (viewport width/height). Rule of thumb: rem for typography, px for borders/shadows, % for widths, vh for full-page sections.

style.css 
/* Absolute — fixed regardless of context */
.px  { font-size: 16px; }  /* always 16px */
.pt  { font-size: 12pt; }  /* 1pt = 1.333px */

/* em — relative to the element's own font-size
   (or parent's if used on font-size itself) */
.em-text  { font-size: 1.25em; }   /* 25% bigger than parent */
.em-space { padding: 1em; }        /* padding = 1× the font-size */

/* rem — relative to the root (html) font-size */
html { font-size: 16px; }
.rem-text  { font-size: 1.5rem; }  /* always 24px */
.rem-space { padding: 1.5rem; }    /* always 24px */

/* % — percentage of parent's value */
.half-width  { width: 50%; }
.line-height { line-height: 150%; } /* same as 1.5 */

/* Viewport */
.full-screen { height: 100vh; width: 100vw; }
.half-vh     { height: 50vh; }
✏️ Your Task

Create four text elements — one each in px, em, rem, and % for font-size. Nest the em element inside a div with a large font-size — notice em compounds! The rem element always stays consistent. This demonstrates why rem is preferred for typography.

Phase 2
Modern Units: svh, dvh, cqi and More
💡 Concept

New CSS units: svh (small viewport height — excludes mobile browser chrome), dvh (dynamic viewport height — updates as browser chrome hides/shows), cqi (container query inline size %). lh (current line height). ch (width of '0' character — good for code blocks). min/max/clamp() are functions, not units — but work everywhere a length is expected.

style.css 
/* Modern viewport units (mobile-safe) */
.hero { min-height: 100svh; }  /* small viewport — excludes browser chrome */
.hero { min-height: 100dvh; }  /* dynamic viewport — updates as chrome hides */

/* Character-based */
.code-block { max-width: 72ch; }  /* max 72 characters wide */
.readable   { max-width: 65ch; }  /* optimal reading width */

/* Line height based */
.icon-size { width: 1lh; height: 1lh; } /* icon same height as text line */

/* Clamp — fluid between min and max */
h1 { font-size: clamp(1.5rem, 5vw, 3rem); }
.container { padding: clamp(16px, 5vw, 48px); }

/* Container query units */
.card { font-size: clamp(.875rem, 2cqi, 1.125rem); }
✏️ Your Task

Use clamp() for a fluid heading: font-size: clamp(1.5rem, 5vw, 3.5rem). Resize your browser — the font size should grow with the viewport but never exceed 3.5rem. Use max-width: 65ch on a paragraph — it limits line length to approximately 65 characters.
