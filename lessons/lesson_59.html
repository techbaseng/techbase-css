📚 2 phases 🏗️ Build: My Button Design System
Phase 1 of 2
Variants and sizes
📖 Concept

Base: display:inline-flex; align-items:center; gap:8px; border:none; cursor:pointer; font-family:inherit;. Variants: primary, secondary, outline, ghost, danger. Sizes: xs, sm, md, lg, xl. State: :active{transform:translateY(1px)}.

style.css
.btn { display:inline-flex; align-items:center; gap:8px; padding:10px 20px; border-radius:9px; font-weight:700; font-size:14px; font-family:inherit; border:none; cursor:pointer; transition:background .15s,transform .15s,box-shadow .15s; }
.btn:active { transform: translateY(1px); }
.btn:disabled { opacity:.45; cursor:not-allowed; pointer-events:none; }
.btn-primary { background:#0284c7; color:white; }
.btn-primary:hover { background:#0369a1; box-shadow:0 4px 12px rgba(2,132,199,.3); }
.btn-outline { background:transparent; color:#0284c7; border:2px solid #0284c7; }
.btn-outline:hover { background:#0284c7; color:white; }
✏️ Your Task

Build 5 variants (primary, secondary, outline, ghost, danger) and 4 sizes. Add :focus-visible outline for keyboard accessibility.

Phase 2 of 2
Loading, icon and pill buttons
📖 Concept

Loading: ::after spinner + pointer-events:none. Icon button: aspect-ratio:1; width:40px. Pill: border-radius:100px. Group: remove middle border-radius, add divider.

style.css
.btn-loading::after { content:''; width:14px; height:14px; border:2px solid rgba(255,255,255,.4); border-top-color:white; border-radius:50%; animation:btn-spin .7s linear infinite; }
@keyframes btn-spin { to { transform:rotate(360deg); } }
.btn-icon { aspect-ratio:1; padding:0; width:40px; }
.btn-pill  { border-radius:100px; }
✏️ Your Task

Add a loading state: on click, add .btn-loading class. After 2s, remove it. This is how real async buttons work.
