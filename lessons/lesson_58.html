Style images with border-radius, shadows, filters and hover effects

📚 2 phases 🏗️ Build: My Image Styling Showcase
Phase 1 of 2
Shapes and frames
📖 Concept

Round corners: border-radius: 50% = circle. Frame: border + box-shadow. Responsive: max-width:100%; height:auto. Object-fit: cover fills without distortion.

style.css
.circle { border-radius: 50%; object-fit: cover; }
.framed { border: 4px solid white; box-shadow: 0 4px 20px rgba(0,0,0,.15); border-radius:12px; }
.polaroid { background: white; padding: 12px 12px 40px; box-shadow: 0 4px 20px rgba(0,0,0,.12); transform: rotate(-2deg); transition: transform .3s; }
.polaroid:hover { transform: rotate(0deg) scale(1.05); }
✏️ Your Task

Style 3 images: (1) circle with outline ring, (2) polaroid with rotation + hover, (3) framed with shadow.

Phase 2 of 2
CSS Filters
📖 Concept

filter: grayscale(100%), blur(4px), brightness(1.3), sepia(0.8), hue-rotate(90deg). Hover colour reveal: go from grayscale to saturated.

style.css
.photo { filter: grayscale(100%); transition: filter .4s ease; }
.photo:hover { filter: grayscale(0%) saturate(1.3); }
.vintage { filter: sepia(.6) contrast(1.1) brightness(1.05); }
✏️ Your Task

Apply grayscale to a set of images. On hover reveal the colour with a 0.4s transition — this is a popular portfolio effect.
