📚 2 phases 🏗️ Build: My Advanced Transitions Demo
Phase 1 of 2
Multiple transitions and stagger
📖 Concept

Multiple transitions: comma-separate with different durations/timing. Stagger via transition-delay on each child. Parent hover reveals menu items one by one.

style.css
.card { transition: transform .3s ease, box-shadow .3s ease, border-color .2s, background .2s; }
/* Stagger */
.menu li { opacity:0; transform:translateX(-10px); transition:opacity .25s,transform .25s; }
.menu:hover li:nth-child(1){ opacity:1; transform:none; transition-delay:0s; }
.menu:hover li:nth-child(2){ opacity:1; transform:none; transition-delay:.1s; }
.menu:hover li:nth-child(3){ opacity:1; transform:none; transition-delay:.2s; }
✏️ Your Task

Build a staggered dropdown: hover the parent to reveal 4 menu items with 0.1s delay increments.

Phase 2 of 2
cubic-bezier and will-change
📖 Concept

cubic-bezier(0.34,1.56,0.64,1) = spring (overshoots). Use cubic-bezier.com to design curves. will-change:transform hints GPU layer — use sparingly.

style.css
.spring    { transition: transform .5s cubic-bezier(0.34,1.56,0.64,1); }
.snappy    { transition: transform .4s cubic-bezier(0.16,1,0.3,1); }
.anticipate{ transition: transform .5s cubic-bezier(0.68,-0.55,0.27,1.55); }
.anim { will-change: transform; }
✏️ Your Task

Compare 5 timing functions by hovering each row: linear, ease, spring, snappy, anticipate. The spring overshoots and bounces back — only possible with cubic-bezier.
