CSS Flex Items

Phase 1
flex-grow, flex-shrink and flex-basis
💡 Concept

flex-grow — how much an item grows to fill extra space (0 = no grow, 1 = grow proportionally). flex-shrink — how much an item shrinks when space is tight (0 = never shrink, 1 = shrink proportionally). flex-basis — the starting size before grow/shrink applies. Shorthand: flex: grow shrink basis. Common: flex: 1 (grow to fill), flex: 0 0 200px (fixed 200px — no grow/shrink).

style.css 
/* flex shorthand */
.flex-1    { flex: 1; }          /* grow: 1, shrink: 1, basis: 0 */
.flex-2    { flex: 2; }          /* grows 2× as fast as flex-1 */
.flex-none { flex: none; }       /* don't grow or shrink */
.flex-auto { flex: auto; }       /* size: auto, can grow/shrink */

/* Individual properties */
.item { flex-grow: 1; flex-shrink: 1; flex-basis: 200px; }

/* Fixed width sidebar */
.sidebar { flex: 0 0 240px; }  /* never grow, never shrink, always 240px */
.content { flex: 1; }          /* fill remaining space */

/* Three unequal columns */
.col-1 { flex: 1; }   /* 1/6 of space */
.col-2 { flex: 2; }   /* 2/6 of space */
.col-3 { flex: 3; }   /* 3/6 of space */
✏️ Your Task

Create a flex row with three items. Give them flex: 1, flex: 2, and flex: 3 respectively. The second should be twice the width of the first, and the third three times. This is much more elegant than calculating percentages!

Phase 2
order and align-self
💡 Concept

order changes the visual order of an item without changing the HTML. Default is 0 — lower numbers appear first. align-self overrides align-items for a single item: flex-start, flex-end, center, stretch. Use margin: auto on a flex item to push other items away — this is how the 'push button to end of nav' trick works.

style.css 
/* order — visual reorder without changing HTML */
.item-1 { order: 3; }  /* appears third */
.item-2 { order: 1; }  /* appears first */
.item-3 { order: 2; }  /* appears second */

/* align-self — override for single item */
.tall    { align-self: flex-start; }   /* sticks to top */
.stretch { align-self: stretch; }      /* fills full height */
.bottom  { align-self: flex-end; }     /* sticks to bottom */

/* margin auto — push items apart */
.nav { display: flex; align-items: center; }
.nav .logo { margin-right: auto; }  /* logo left, rest right */
.nav .cta  { margin-left: 12px; }   /* gap before CTA button */

/* Card footer pushed to bottom */
.card { display: flex; flex-direction: column; }
.card-body { flex: 1; }        /* grows to fill space */
.card-footer { margin-top: auto; } /* always at the bottom */
✏️ Your Task

Create a card with display: flex; flex-direction: column;. Give the card body flex: 1 so it stretches. Give the card footer margin-top: auto so it always sticks to the bottom, even if the card content is short. This makes cards in a grid always have aligned footers!
