Phase 1 of 2
fill-mode, play-state and direction
📖 Concept

fill-mode:forwards keeps the final keyframe state. both = forwards + backwards. play-state:paused freezes. direction:alternate reverses on even iterations (ping-pong).

style.css
.item { animation: fadeUp .5s ease both; } /* stays visible, invisible during delay */
.item:nth-child(1){ animation-delay:.1s }
.item:nth-child(2){ animation-delay:.25s }
.spinning:hover   { animation-play-state: paused; }
.pingpong { animation: slide 1s ease-in-out infinite alternate; }
✏️ Your Task

Create stagger cards with fill-mode:both. Each card is invisible during its delay, then stays visible after.

Phase 2 of 2
Chaining and replay
📖 Concept

Multiple animations on one element: comma-separate. Chain: delay second by duration of first. Replay via JS: remove class → force reflow → re-add.

style.css
.pop-then-pulse { animation: bounceIn .6s ease forwards, pulse 2s ease 1s infinite; }
@keyframes bounceIn { 0%{transform:scale(0) rotate(-10deg);opacity:0} 60%{transform:scale(1.1) rotate(2deg);opacity:1} 100%{transform:scale(1) rotate(0)} }
/* Replay: */
/* el.classList.remove('animate'); void el.offsetWidth; el.classList.add('animate'); */
✏️ Your Task

Build a replay button: remove the class, call void el.offsetWidth (forces reflow), then add the class. This is the only way to restart a CSS animation without reloading.
