Phase 1
Border Style, Width and Colour
💡 Concept

The border property needs three values: width (thickness), style (how it looks), and colour. border: 2px solid #0284c7. Border styles include: solid, dashed, dotted, double, groove, ridge. You can also set individual sides: border-top, border-right, border-bottom, border-left — or mix and match. A popular pattern is border-left only for an accent stripe.

style.css 
/* Shorthand — width style color */
.solid-box  { border: 2px solid #0284c7; }
.dashed-box { border: 2px dashed #ea4f21; }
.dotted-box { border: 3px dotted #10b981; }
.double-box { border: 4px double #7c3aed; }

/* Individual sides */
.top-only    { border-top: 4px solid #0284c7; }
.left-accent { border-left: 5px solid #0284c7; padding-left: 16px; }

/* Mix sides — top and bottom but not sides */
.tb-only {
  border-top: 2px solid #e2e8f0;
  border-bottom: 2px solid #e2e8f0;
}

/* Long form — same as border: 2px solid blue */
.long-form {
  border-width: 2px;
  border-style: solid;
  border-color: #0284c7;
}

/* Different widths per side */
.thick-top {
  border-width: 4px 1px 1px 1px;  /* top right bottom left */
  border-style: solid;
  border-color: #0284c7;
}

Phase 2
Border Radius and Shorthand
💡 Concept

border-radius rounds the corners of an element. border-radius: 8px rounds all 4 corners equally. Four values: border-radius: 8px 0 8px 0 — top-left, top-right, bottom-right, bottom-left. A perfect circle: set border-radius: 50% on a square element. The border shorthand combines all three values: border: 2px solid #0284c7; is the most common pattern.

style.css 
/* All corners equally rounded */
.rounded     { border: 2px solid #0284c7; border-radius: 8px; }
.very-round  { border: 2px solid #0284c7; border-radius: 20px; }
.pill        { border: 2px solid #0284c7; border-radius: 100px; }

/* Perfect circle (on a square element) */
.circle {
  width: 100px;
  height: 100px;
  border: 3px solid #0284c7;
  border-radius: 50%;
}

/* Different radii per corner */
.custom-radius {
  border: 2px solid #0284c7;
  border-radius: 20px 0 20px 0; /* diagonal rounding */
}

/* Card with border-radius and shadow */
.card {
  border: 1.5px solid #e2e8f0;
  border-radius: 14px;
  padding: 24px;
  box-shadow: 0 2px 8px rgba(2,132,199,.12);
  background: white;
}
