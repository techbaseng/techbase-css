Phase 1
Background Colour and Image
💡 Concept

background-color fills an element with a solid colour. background-image: url('image.jpg') sets an image background. By default the image tiles to fill the element. Control tiling with background-repeat: no-repeat | repeat-x | repeat-y | repeat. Position it with background-position: center | top right | 50% 50%. Control size with background-size: cover (fills without distortion), contain (fits inside), or exact dimensions like 200px 100px.

style.css 
/* Solid background colour */
.hero { background-color: #0284c7; }

/* Background image — tiling by default */
.pattern { background-image: url('pattern.png'); }

/* No repeat — show image once */
.banner {
  background-image: url('banner.jpg');
  background-repeat: no-repeat;
  background-position: center;
  background-size: cover;    /* Fill without distortion */
  height: 300px;
}

/* Contain — show whole image, may leave gaps */
.logo-bg {
  background-image: url('logo.png');
  background-repeat: no-repeat;
  background-position: center;
  background-size: contain;
  height: 200px;
}

/* Multiple backgrounds — comma separated */
.layered {
  background:
    url('overlay.png') no-repeat center,
    url('texture.jpg') repeat;
}

Phase 2
CSS Gradients
💡 Concept

CSS gradients create smooth colour transitions — no image file needed! linear-gradient(direction, colour1, colour2) — direction can be to right, to bottom right, or an angle like 135deg. radial-gradient(shape, colour1, colour2) radiates from the centre outward. You can add multiple colour stops: linear-gradient(to right, #0284c7, #7c3aed, #ea4f21). Gradients work anywhere a colour or image is expected.

style.css 
/* Linear gradient — left to right */
.grad-1 { background: linear-gradient(to right, #0284c7, #7c3aed); }

/* Diagonal gradient */
.grad-2 { background: linear-gradient(135deg, #ea4f21, #d97706); }

/* Three colour stops */
.rainbow { background: linear-gradient(to right, #ea4f21, #d97706, #10b981); }

/* Gradient with specific stop positions */
.precise {
  background: linear-gradient(
    to right,
    #0284c7 0%,
    #0284c7 40%,   /* stays blue until 40% */
    #7c3aed 60%,   /* purple from 60% */
    #7c3aed 100%
  );
}

/* Radial gradient */
.glow {
  background: radial-gradient(circle at center,
    rgba(2,132,199,.5) 0%,
    transparent 70%
  );
}

/* Gradient on text! */
.gradient-text {
  background: linear-gradient(to right, #0284c7, #ea4f21);
  -webkit-background-clip: text;
  -webkit-text-fill-color: transparent;
  font-size: 2rem; font-weight: bold;
}

        font-weight: bold; font-size: 15px;

        color: white; text-shadow: 0 1px 3px rgba(0,0,0,.3);
      }
      .grid { display: flex; flex-wrap: wrap; gap: 14px; }
      .grid .demo { flex: 1; min-width: 200px; }

      /* ── SOLID COLOUR ── */

                    #7c3aed 0%, #0284c7 60%, #0f172a 100%); }
      .grad-dark { background: linear-gradient(135deg, #0f172a 0%, #1e293b 100%); }

      /* ── IMAGE BACKGROUND ── */

        background-position: center;

        background: linear-gradient(to right, #0284c7, #7c3aed, #ea4f21);
        -webkit-background-clip: text;
        -webkit-text-fill-color: transparent;

        text-align: center;
