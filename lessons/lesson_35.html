Phase 1
Exact and Partial Attribute Matching
💡 Concept

CSS attribute selectors target elements based on their attributes and values. [attr] — has the attribute. [attr='val'] — exact value. [attr^='val'] — starts with. [attr$='val'] — ends with. [attr*='val'] — contains anywhere. [attr~='val'] — word in space-separated list. [attr|='val'] — exact or starts with 'val-'.

style.css 
/* Has the attribute */
input[required]     { border-color: #ef4444; }
input[disabled]     { opacity: .5; }
a[target]           { font-weight: bold; }

/* Exact value */
input[type="email"] { border-color: #0284c7; }
input[type="text"]  { border-color: #94a3b8; }

/* Starts with */
a[href^="https"]    { color: #10b981; }
a[href^="mailto"]   { color: #0284c7; }

/* Ends with */
a[href$=".pdf"]::after  { content: ' 📄'; }
a[href$=".zip"]::after  { content: ' 📦'; }
img[src$=".png"]        { border: 2px solid #e2e8f0; }

/* Contains */
a[href*="github"]   { color: #7c3aed; }
[class*="btn"]      { cursor: pointer; }

/* Case insensitive with i flag */
a[href$=".PDF" i]   { color: #ea4f21; }

Phase 2
Attribute Selectors for Forms and UI
💡 Concept

Attribute selectors shine in form styling. Target different input types, required vs optional fields, disabled states. Combine with pseudo-classes for powerful rules: input[type='checkbox']:checked + label. Also useful for: styling data attributes ([data-theme='dark']), ARIA roles ([role='button']), and language attributes ([lang='fr']).

style.css 
/* Style by input type */
input[type="text"]     { border-left: 3px solid #94a3b8; }
input[type="email"]    { border-left: 3px solid #0284c7; }
input[type="password"] { border-left: 3px solid #ea4f21; }
input[type="number"]   { border-left: 3px solid #10b981; }

/* Required fields */
input[required] + label::after,
input[required] ~ label::after {
  content: ' *';
  color: #ef4444;
}

/* Data attributes for theme */
[data-theme="dark"]  { background: #0f172a; color: white; }
[data-theme="light"] { background: white; color: #0f172a; }

/* ARIA */
[role="button"] { cursor: pointer; }
[aria-disabled="true"] { opacity: .5; pointer-events: none; }
