Phase 1
Selectors, Properties and Values
💡 Concept

A CSS rule has three parts: the selector (which HTML element to target), the property (what to change), and the value (how to change it). They are written as: selector { property: value; }. The property and value together form a declaration. Multiple declarations go inside curly braces { }, each ending with a semicolon ;.

style.css 
/* Full CSS rule anatomy:
   selector { property: value; }  */

/* Single declaration */
h1 { color: #0284c7; }

/* Multiple declarations (one per line is best practice) */
p {
  color: #334155;
  font-size: 16px;
  line-height: 1.8;
  margin-bottom: 12px;
}

/* Multiple selectors — same rules apply to both */
h1, h2 {
  font-family: Arial, sans-serif;
  font-weight: 700;
}

Phase 2
CSS Comments and White Space
💡 Concept

CSS comments start with /* and end with */. Everything between is ignored by the browser — great for notes! White space (spaces, tabs, line breaks) in CSS is ignored by the browser, so you can format your code however you like. Convention: one property per line, 2-space indent inside each rule, blank line between rules.

style.css 
/* ===========================
   My Website Styles
   Author: Tunde
   =========================== */

/* Navigation */
nav {
  background-color: #0284c7;
  padding: 14px 24px;
}

/* The same rule condensed — works but hard to read */
nav { background-color: #0284c7; padding: 14px 24px; }

/* Good practice: one declaration per line */
nav a {
  color: white;           /* link colour */
  text-decoration: none;  /* remove underline */
  font-weight: bold;      /* bold text */
  margin-right: 20px;     /* spacing between links */
}
