CSS Max-width

Keep content readable on large screens using max-width and the centring trick. Work through 2 phases — complete each task before clicking Next Phase.

Phase 1
The Centring Pattern
💡 Concept

max-width caps an element's width — narrower on small screens, never wider. The classic pattern: max-width: 860px; width: 100%; margin: 0 auto; padding: 0 20px;. This creates a centred column that fills screens on mobile but stops at 860px on desktop. Aim for 45–80 characters per line for best readability.

style.css 
/* The standard centred layout */
.container {
  max-width: 860px;
  width: 100%;
  margin: 0 auto;
  padding: 0 20px;
}

/* Narrow article (optimal reading width) */
.article { max-width: 680px; margin: 0 auto; }

/* Full-bleed background with centred content */
.hero-bg { background: #0284c7; padding: 60px 20px; }
.hero-bg .inner { max-width: 860px; margin: 0 auto; color: white; }

Phase 2
Min-width and Responsive Combinations
💡 Concept

min-width stops an element shrinking below a value. Combine: min-width: 280px; max-width: 900px; width: 100%;. width: fit-content shrinks to content. img { max-width: 100%; height: auto; } prevents images overflowing — add this to every stylesheet.

style.css 
/* Always between min and max */
.flexible { min-width: 300px; max-width: 700px; width: 100%; }

/* Images that never overflow */
img { max-width: 100%; height: auto; }

/* Buttons that are always tappable */
.btn { min-width: 120px; padding: 10px 20px; }

/* Content-sized element */
.tag { width: fit-content; padding: 4px 12px; border-radius: 100px; }
✏️ Your Task

Add img { max-width: 100%; height: auto; } to your stylesheet. Try putting an oversized image — it should stop at the container edge. Add min-width: 120px to your buttons.

🏗️ Build It!
My Readable Layout Page

Build a full-page layout with full-width sections and a max-width centred content area.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Max-width Layout</title>
    <style>
      *, *::before, *::after { box-sizing: border-box; }
      body { font-family: Arial, sans-serif; margin: 0; background: #f0f9ff; color: #0f172a; }
      .container { max-width: 860px; margin: 0 auto; width: 100%; padding: 0 24px; }
      .hero { background: linear-gradient(135deg, #0284c7, #0369a1); padding: 80px 24px; color: white; text-align: center; }
      .hero h1 { font-size: clamp(1.8rem, 4vw, 3rem); margin-bottom: 12px; }
      .hero p  { opacity: .85; max-width: 520px; margin: 0 auto 24px; font-size: 1.05rem; }
      .hero a  { display: inline-block; background: white; color: #0284c7; padding: 12px 28px; border-radius: 10px; font-weight: bold; text-decoration: none; }
      .section { padding: 56px 0; }
      .section h2 { color: #0284c7; font-size: 1.6rem; margin-bottom: 16px; }
      .section p  { color: #334155; line-height: 1.8; margin-bottom: 14px; max-width: 680px; }
      .cards { display: flex; gap: 20px; flex-wrap: wrap; margin-top: 20px; }
      .card  { flex: 1; min-width: 200px; background: white; border: 1.5px solid #bae6fd; border-radius: 14px; padding: 22px; }
      .card h3 { color: #0284c7; margin: 0 0 8px; }
      .card p  { color: #475569; font-size: 14px; margin: 0; }
      .blue-band { background: #0284c7; color: white; padding: 40px 24px; }
      .blue-band h2 { margin-bottom: 8px; }
      .blue-band p  { opacity: .85; max-width: 560px; }
      footer { background: #0f172a; color: rgba(255,255,255,.5); text-align: center; padding: 24px; font-size: 13px; }
      hr { border: none; border-top: 1px solid #e2e8f0; }
    </style>
  </head>
  <body>
    <div class="hero">
      <h1>Max-width Layout</h1>
      <p>Background goes edge-to-edge. Content stays centred and readable at any screen width.</p>
      <a href="#content">See How It Works ↓</a>
    </div>
    <div class="section" id="content">
      <div class="container">
        <h2>Centred at max-width: 860px</h2>
        <p>This container uses <code>max-width: 860px; margin: 0 auto;</code>. On small screens it fills the width. On large screens it stays 860px and centres.</p>
        <div class="cards">
          <div class="card"><h3>Mobile</h3><p>width: 100% — fills the phone screen.</p></div>
          <div class="card"><h3>Tablet</h3><p>Still fills but padding gives breathing room.</p></div>
          <div class="card"><h3>Desktop</h3><p>Capped at 860px, centred with auto margins.</p></div>
        </div>
      </div>
    </div>
    <hr>
    <div class="blue-band">
      <div class="container">
        <h2>Full-width Band, Centred Content</h2>
        <p>The blue background fills the whole viewport. Text uses the same .container class to stay at most 860px wide.</p>
      </div>
    </div>

  </body>
</html>
