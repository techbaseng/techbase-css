Portfolio structure and theme
📖 Concept

Your final CSS portfolio demonstrates mastery of all 73 lessons: custom variables, box-sizing reset, responsive layout, Flexbox, Grid, transitions, animations, 3D transforms, tooltips, buttons, web fonts, text effects, backdrop-filter and glassmorphism. Build section by section: sticky glassmorphism navbar, animated hero, grid project cards, skills bars, contact form, footer.

Build your portfolio page section by section: (1) sticky glassmorphism navbar, (2) animated gradient hero, (3) project card grid, (4) skills progress bars, (5) styled contact form, (6) footer. Use CSS variables for every colour.

Phase 2 of 2
Polish, deploy and celebrate
📖 Concept

Polish checklist: ✅ CSS variables. ✅ border-box reset. ✅ scroll-behavior:smooth. ✅ prefers-reduced-motion. ✅ dark mode. ✅ max-width:100% on images. ✅ focus-visible rings. ✅ Responsive at 320/768/1024px. Then push to GitHub Pages!
