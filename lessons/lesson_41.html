CSS !important

Understand when and why to use !important — and why it's usually better to avoid it. Work through 2 phases — complete each task before clicking Next Phase.

Phase 1
What !important Does
💡 Concept

!important overrides ALL other declarations for a property, regardless of specificity. Syntax: color: red !important;. When two !important declarations conflict, specificity applies again. When to use: (1) utility classes that MUST win (Bootstrap/Tailwind use this). (2) Third-party CSS overrides. (3) Accessibility overrides (high-contrast mode). When NOT to use: never as a fix for specificity problems — fix the selectors instead.

style.css 
/* !important overrides specificity */
#header .nav a { color: gray; }    /* 1-1-1 — very specific */
a { color: blue !important; }      /* 0-0-1 but !important — WINS */

/* Utility class pattern */
.text-red   { color: #ef4444 !important; }
.text-blue  { color: #0284c7 !important; }
.text-green { color: #10b981 !important; }
.hidden     { display: none !important; }
.mt-0       { margin-top: 0 !important; }

/* When two !important clash, specificity applies */
p { color: red !important; }           /* 0-0-1 */
.special { color: blue !important; }   /* 0-1-0 — class wins */

/* ❌ BAD — fighting specificity with !important */
#sidebar p { color: gray; }
p { color: blue !important; } /* wrong fix — change the selector instead */

/* ✅ GOOD — fix the selector instead */
#sidebar p { color: blue; } /* increase specificity properly */

Phase 2
Practical !important Uses
💡 Concept

Legitimate uses: override third-party library styles (Bootstrap, Google Maps, embed iframes). Utility-first CSS frameworks (Tailwind) use !important on every utility class. Browser accessibility stylesheets use !important. Print stylesheets often use !important to hide decorative elements. The alternative to !important is usually better selector specificity or restructuring the CSS.

style.css 
/* Override third-party widget */
.google-maps-container { height: 400px !important; }

/* Print stylesheet — hide unnecessary elements */
@media print {
  .navbar, .sidebar, .cookie-banner { display: none !important; }
  body { font-size: 12pt !important; color: black !important; }
}

/* Accessibility — respect user preferences */
@media (prefers-contrast: high) {
  * { background: white !important; color: black !important; }
  a { color: blue !important; }
}

/* Animation override during page transitions */
.no-animate * { animation: none !important; transition: none !important; }

/* The 'right' way instead of !important */
/* Add a class higher in the chain instead of !important */
.page-override p { color: blue; }  /* higher specificity, no !important */
✏️ Your Task

Create a print stylesheet: add @media print { .navbar, .sidebar { display: none !important; } }. Then click File → Print (or Ctrl+P) in your browser and preview — the navbar should disappear in print mode! This is how print-friendly pages work.

🏗️ Build It!
My !important Examples

Build a page with utility classes using !important and a print-friendly stylesheet.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS !important</title>
    <style>
      *, *::before, *::after { box-sizing: border-box; }
      body { font-family: Arial, sans-serif; background: #f0f9ff; padding: 30px; max-width: 860px; margin: 0 auto; color: #0f172a; }
      h1 { color: #0284c7; margin-bottom: 6px; }
      h2 { color: #0369a1; margin: 28px 0 14px; border-bottom: 2px solid #bae6fd; padding-bottom: 6px; }
      .demo { background: white; border: 1.5px solid #bae6fd; border-radius: 12px; padding: 20px; margin-bottom: 14px; }
      code { background: #dbeafe; color: #1e40af; padding: 2px 6px; border-radius: 4px; font-family: monospace; font-size: 12px; }
      /* High specificity rule */
      #demo-section .inner-div p { color: #94a3b8; font-size: 14px; }
      /* !important overrides the high-specificity rule above */
      .text-override { color: #0284c7!important; font-weight: bold!important; }
      /* Utility classes */
      .text-red   { color: #ef4444!important; }
      .text-blue  { color: #0284c7!important; }
      .text-green { color: #10b981!important; }
      .text-purple{ color: #7c3aed!important; }
      .fw-bold    { font-weight: 700!important; }
      .hidden     { display: none!important; }
      .mt-0       { margin-top: 0!important; }
      .rounded    { border-radius: 100px!important; }
      /* Utility demo tags */
      .util-tag { display: inline-block; padding: 6px 16px; background: #e2e8f0; border-radius: 8px; margin: 4px; font-size: 14px; }
    </style>
    <style media="print">
      .no-print { display: none!important; }
      body { background: white!important; color: black!important; }
      h1, h2 { color: black!important; }
    </style>
  </head>
  <body>
    <h1>CSS !important</h1>

    <h2>!important Overrides High Specificity</h2>
    <div class="demo" id="demo-section">
      <div class="inner-div">
        <p>This paragraph is grey — targeted by a very high-specificity rule (1-0-3 effectively).</p>
        <p class="text-override">This paragraph has <code>color: #0284c7 !important</code> — it wins despite the low specificity of the class selector!</p>
      </div>
    </div>

    <h2>Utility Classes with !important</h2>
    <div class="demo">
      <p>Apply utility classes to override any colour:</p>
      <span class="util-tag text-red fw-bold">text-red</span>
      <span class="util-tag text-blue fw-bold">text-blue</span>
      <span class="util-tag text-green fw-bold">text-green</span>
      <span class="util-tag text-purple fw-bold">text-purple</span>
      <span class="util-tag rounded text-blue">rounded</span>
    </div>

    <h2>Hidden Element</h2>
    <div class="demo">
      <p>The div below uses <code>display: none!important</code>:</p>
      <div class="hidden" style="background:#ef4444;padding:12px;color:white">You can't see me! (display: none!important)</div>
      <p style="color:#10b981;font-weight:bold">The red div is hidden with .hidden class.</p>
    </div>

    <div class="no-print" style="background:#fef3c7;border-left:4px solid #d97706;padding:14px 18px;border-radius:0 10px 10px 0;margin-top:20px;">
      <strong>🖨️ Print test:</strong> Press Ctrl+P to preview print — this yellow box and the navigation vanish thanks to <code>@media print { .no-print { display: none!important; } }</code>
    </div>
  </body>
</html>
