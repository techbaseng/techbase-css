Phase 1
Font Family Stacks and Google Fonts
💡 Concept

font-family takes a comma-separated font stack — the browser uses the first available, falling back to the next. End with a generic: serif, sans-serif, monospace. Google Fonts is free and has 1,500+ fonts. Add the link tag from fonts.google.com in the head, then use the font name in CSS.

index.html 
<!-- Link Google Fonts in <head> -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&family=Merriweather:ital,wght@0,400;0,700;1,400&family=JetBrains+Mono&display=swap" rel="stylesheet">

<style>
  body    { font-family: 'Inter', Arial, sans-serif; }
  article { font-family: 'Merriweather', Georgia, serif; }
  code    { font-family: 'JetBrains Mono', 'Courier New', monospace; }

  /* System font stack — no download, looks native */
  .system { font-family: -apple-system, BlinkMacSystemFont,
                         'Segoe UI', Roboto, Arial, sans-serif; }
</style>

Phase 2
Size, Weight, Style and the Shorthand
💡 Concept

font-size: use rem for accessible scaling (1rem = 16px). font-weight: 100–900 (or normal=400, bold=700). font-style: italic. The shorthand: font: italic 700 1.2rem/1.6 Arial, sans-serif (style weight size/line-height family).

style.css 
/* Font sizes with rem */
.xs  { font-size: 0.75rem; }  /* 12px */
.sm  { font-size: 0.875rem; } /* 14px */
.md  { font-size: 1rem; }     /* 16px */
.lg  { font-size: 1.25rem; }  /* 20px */
.xl  { font-size: 1.5rem; }   /* 24px */
.xxl { font-size: 2rem; }     /* 32px */

/* Weights */
.light    { font-weight: 300; }
.regular  { font-weight: 400; }
.semibold { font-weight: 600; }
.bold     { font-weight: 700; }
.black    { font-weight: 900; }

/* Shorthand: style weight size/line-height family */
.shorthand { font: italic 700 1.2rem/1.6 'Inter', sans-serif; }
