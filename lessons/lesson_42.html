CSS Math Functions

Use calc(), min(), max(), clamp() and round() for dynamic, responsive CSS calculations. Work through 2 phases — complete each task before clicking Next Phase.

Phase 1
calc() for Dynamic Values
💡 Concept

calc() performs maths inside CSS values. Mix units: calc(100% - 48px) (full width minus 48px padding). Use any operator: +, -, *, /. Always put spaces around + and - operators. Common uses: sidebar + content that fills the rest of the width, off-set an element by the header height, create consistent spacing ratios.

style.css 
/* Sidebar + content fill exactly 100% */
.sidebar { width: 240px; float: left; }
.content { width: calc(100% - 240px); float: left; }

/* Full height minus header */
.main { min-height: calc(100vh - 62px); }

/* Consistent spacing */
:root { --spacing: 16px; }
.card { padding: calc(var(--spacing) * 1.5); } /* 24px */
.card-sm { padding: calc(var(--spacing) * 0.75); } /* 12px */

/* Centred element with offset */
.off-centre {
  position: absolute;
  left: calc(50% + 20px);
  transform: translateX(-50%);
}

/* Grid gap that accounts for a border */
.grid { gap: calc(16px - 1px); } /* accounts for 1px borders */
✏️ Your Task

Use calc(100% - 240px) to create a layout where a 240px sidebar and a fluid main content fill exactly 100% of the width. Then use calc(100vh - 62px) to give the main area the remaining height below a 62px header.

Phase 2
min(), max() and clamp()
💡 Concept

min(a, b) takes the smaller of two values — useful for width that shrinks on mobile: width: min(600px, 100%). max(a, b) takes the larger — useful for minimum sizes. clamp(min, preferred, max) constrains a value between min and max — the preferred scales fluidly. This is the modern way to write fully responsive typography and spacing without media queries.

style.css 
/* min() — smaller of two values */
.card { width: min(400px, 100%); } /* 400px or full width, whichever is smaller */

/* max() — larger of two values */
.sidebar { width: max(200px, 20%); } /* at least 200px wide */
.text { font-size: max(14px, 1rem); } /* never below 14px */

/* clamp(minimum, preferred, maximum) */
h1 { font-size: clamp(1.5rem, 5vw, 3rem); }
/* = 1.5rem on small screens, 5vw on medium, max 3rem */

.container { padding: clamp(16px, 4vw, 48px); }
/* = 16px on mobile, grows with viewport, max 48px */

.card { width: clamp(280px, 40%, 520px); }
/* = between 280px and 520px, ideally 40% of parent */
✏️ Your Task

Create a heading that uses clamp(1.5rem, 5vw, 3.5rem) for font-size. Resize your browser from very small to very large — the heading should scale fluidly between 1.5rem and 3.5rem. Replace your fixed padding with clamp(16px, 4vw, 48px) for responsive spacing.

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Math Functions</title>
    <style>
      :root { --header-h: 62px; --sidebar-w: 240px; --gap: 24px; }
      *, *::before, *::after { box-sizing: border-box; }
      body { font-family: Arial, sans-serif; background: #f0f9ff; margin: 0; color: #0f172a; }
      /* Header — fixed height */
      .header { height: var(--header-h); background: #0284c7; display: flex; align-items: center; padding: 0 28px; position: sticky; top: 0; z-index: 100; }
      .header h1 { color: white; font-size: 1.1rem; margin: 0; }
      /* Layout using calc() */
      .layout { display: flex; min-height: calc(100vh - var(--header-h)); }
      .sidebar { width: var(--sidebar-w); background: #0f172a; flex-shrink: 0; padding: 24px 12px; }
      .sidebar a { display: block; color: #94a3b8; text-decoration: none; padding: 9px 12px; border-radius: 8px; font-size: 13px; margin-bottom: 2px; }
      .sidebar a:hover { background: rgba(255,255,255,.08); color: white; }
      .main { flex: 1; min-width: 0; padding: clamp(20px, 3vw, 48px); }
      /* Fluid heading with clamp() */
      .fluid-h { font-size: clamp(1.4rem, 4vw, 2.5rem); font-weight: 800; color: #0284c7; margin-bottom: 8px; }
      .sub { color: #64748b; font-size: min(1rem, 4vw); margin-bottom: 28px; }
      /* Demo boxes */
      .demos { display: grid; gap: clamp(12px, 2vw, 24px); }
      .demo { background: white; border: 1.5px solid #bae6fd; border-radius: 12px; padding: 20px; }
      .demo h3 { color: #0369a1; margin: 0 0 8px; font-size: 14px; font-family: monospace; }
      .demo p  { color: #475569; font-size: 13px; line-height: 1.7; margin: 0; }
      /* calc() visual */
      .calc-bar { height: 40px; background: #0284c7; border-radius: 8px; margin-top: 12px;
                  display: flex; align-items: center; justify-content: center;
                  color: white; font-size: 12px; font-weight: bold; }
      .bar-33 { width: min(33.33%, 200px); }
      .bar-50 { width: min(50%, 300px); }
      .bar-75 { width: min(75%, 450px); }
    </style>
