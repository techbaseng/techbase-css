📚 2 phases 🏗️ Build: My Transition Effects Gallery
Phase 1 of 2
transition syntax
📖 Concept

transition: property duration timing delay. Apply on the BASE element — not just :hover — so the animation plays both ways. Timing: ease, linear, ease-in, ease-out, cubic-bezier().

style.css
.card { transition: transform .25s ease, box-shadow .25s ease; }
.card:hover { transform: translateY(-8px); box-shadow: 0 16px 40px rgba(2,132,199,.2); }
.btn  { transition: background .15s; }
.btn:hover { background: #0369a1; }
✏️ Your Task

Add a lift effect to a card: transition on the card element (not :hover), then translateY and shadow on :hover.

Phase 2 of 2
What can transition
📖 Concept

✅ GPU-accelerated (best): transform, opacity. ✅ Works: background-color, border-color, font-size. ❌ Cannot: display, height auto, gradients. Use transform: scaleX() instead of width for progress bars.

style.css
.prog { transform: scaleX(0.6); transform-origin: left; transition: transform .4s cubic-bezier(.22,1,.36,1); }
.fade { opacity: 0; transition: opacity .3s ease; }
.fade:hover { opacity: 1; }
✏️ Your Task

Build a progress bar using transform: scaleX() — set transform-origin: left and animate from scaleX(0) to scaleX(1).
