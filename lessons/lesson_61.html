Create newspaper-style layouts using CSS multi-column properties

📚 2 phases 🏗️ Build: My Multi-column Article
Phase 1 of 2
column-count and column-width
📖 Concept

column-count: 3 = exactly 3 cols. column-width: 250px = as many 250px cols as fit. column-gap: 32px sets the gutter. column-rule: 1px solid #e2e8f0 adds a divider. column-span: all lets an element span all columns.

style.css
.article { column-count: 3; column-gap: 32px; column-rule: 1px solid #e2e8f0; }
.headline { column-span: all; }
.card     { break-inside: avoid; }
✏️ Your Task

Apply 3-column CSS to a long article. Add a column-span:all pull quote — it breaks out across the full width.

Phase 2 of 2
break-inside and column-fill
📖 Concept

break-inside: avoid prevents cards/images splitting across columns. break-before: column starts a new column before the element. column-fill: balance (default) equalises heights.

style.css
figure   { break-inside: avoid; }
.callout { break-inside: avoid; background:#dbeafe; border-left:4px solid #0284c7; padding:12px; }
@media(max-width:600px){ .article { column-count:1; } }
✏️ Your Task

Add a callout box with break-inside:avoid. Without it, the box splits in half across columns. With it, the whole box stays in one column.
