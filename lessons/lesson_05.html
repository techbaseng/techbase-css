Phase 1
Writing CSS Comments
💡 Concept

CSS comments use /* comment here */ syntax — everything between is ignored by the browser. They can span multiple lines. Use comments to: explain complex rules, label sections of your stylesheet, temporarily disable CSS for testing, and leave TODO notes. Good commenting is a professional habit that makes your code readable months later — or for other developers working on the same project.

style.css 
/* ============================================
   My Website Stylesheet
   Author: Tunde Awoyemi
   Created: January 2025
   Version: 1.0
   ============================================ */

/* ── RESET ── */
* { box-sizing: border-box; margin: 0; padding: 0; }

/* ── TYPOGRAPHY ── */
body {
  font-family: 'Segoe UI', Arial, sans-serif; /* Readable web font stack */
  font-size: 16px;      /* Base font size */
  line-height: 1.7;     /* Comfortable reading */
  color: #334155;       /* Soft dark text — not pure black */
}

/* ── COLOURS ──
   Primary:   #0284c7 (sky blue)
   Secondary: #0369a1 (dark blue)
   Accent:    #ea4f21 (orange)
   ─────────────────────────────── */
h1 { color: #0284c7; }
h2 { color: #0369a1; }

Phase 2
Comments for Debugging and TODOs
💡 Concept

Commenting out CSS is a great debugging tool — wrap any rule in /* ... */ to temporarily disable it and see what changes. You can also use comments as TODO reminders: /* TODO: Add mobile breakpoint here */. Some teams use a standard comment format like /* === SECTION === */ or /* -- subsection -- */ to make stylesheet navigation easier.

style.css 
/* ===== NAVIGATION ===== */
nav {
  background: #0284c7;
  padding: 14px 24px;
  /* TODO: Add sticky positioning when scrolling */
}

nav a {
  color: white;
  text-decoration: none;
  /* Previously had: font-size: 14px; — changed to 16px for accessibility */
  font-size: 16px;
}

/* ===== COMMENTED OUT — testing without shadow ===== */
/*
.card {
  box-shadow: 0 4px 14px rgba(2,132,199,.2);
}
*/

/* NOTE: The above shadow was causing performance issues on mobile.
         Re-enable after testing on low-end devices. */
.card {
  border: 1.5px solid #e2e8f0; /* Use border instead of shadow for now */
}

      /* ============================================================
         MY WEBSITE STYLESHEET
         Author:  [Your Name]
         Date:    [Today's Date]
         Project: Techbase CSS Course — Lesson 05
         Version: 1.0
         ============================================================ */

      /* ── RESET & BOX MODEL ─────────────────────────────────────── */
      * {
        box-sizing: border-box; /* Include padding in width calculations */
        margin: 0;
        padding: 0;
      }

      /* ── GLOBAL TYPOGRAPHY ─────────────────────────────────────── */
      body {
        font-family: Arial, sans-serif;
        font-size: 16px;        /* Base size — other sizes relative to this */
        line-height: 1.8;       /* 1.8x the font size for comfortable reading */
        background-color: #f0f9ff;
        color: #334155;         /* Soft dark — better than pure #000 */
        padding: 30px;
        max-width: 800px;
        margin: 0 auto;         /* Centre on large screens */
      }

      /* ── HEADINGS ──────────────────────────────────────────────── */
      /* Colour palette:
           Primary:   #0284c7 (sky blue)
           Secondary: #0369a1 (dark blue)
           ─────────────────────────────── */
      h1 { color: #0284c7; font-size: 2rem; margin-bottom: 8px; }
      h2 { color: #0369a1; margin: 28px 0 14px;
           border-bottom: 2px solid #bae6fd; padding-bottom: 6px; }

      /* ── NAVIGATION ────────────────────────────────────────────── */
      /* TODO: Add responsive hamburger menu for mobile */
      nav {
        background: #0284c7;
        padding: 12px 20px;
        border-radius: 10px;
        margin-bottom: 28px;
        display: flex;
        gap: 20px;
      }
      nav a {
        color: white;
        text-decoration: none;
        font-weight: 600;
        font-size: 14px;
      }
      nav a:hover { text-decoration: underline; } /* Simple hover feedback */

      /* ── CARDS ─────────────────────────────────────────────────── */
      .card {
        background: white;
        border: 1.5px solid #e2e8f0;
        border-radius: 12px;
        padding: 22px;
        margin-bottom: 16px;
        /* NOTE: shadow removed for mobile performance — TODO: test and re-add */
        /* box-shadow: 0 4px 14px rgba(2,132,199,.15); */
      }
      .card h3 { color: #0284c7; margin: 0 0 8px; font-size: 1rem; }
      .card p  { color: #475569; font-size: 14px; line-height: 1.7; margin: 0; }

      /* ── COMMENT LABELS ─────────────────────────────────────────── */
      code {
        background: #dbeafe;
        color: #1e40af;
        padding: 2px 6px;
        border-radius: 4px;
        font-family: 'Courier New', monospace;
        font-size: 13px;
      }

      /* ── FOOTER ────────────────────────────────────────────────── */
      footer {
        border-top: 1px solid #e2e8f0;
        margin-top: 32px;
        padding-top: 16px;
        font-size: 13px;
        color: #94a3b8; /* Muted footer text */
        text-align: center;
      }

    </style>
