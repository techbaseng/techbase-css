📚 2 phases 🏗️ Build: My 3D Transform Showcase
Phase 1 of 2
perspective and rotateX/Y
📖 Concept

perspective on the PARENT sets the viewing distance. Smaller = more extreme. rotateX(45deg) tips the element. rotateY(45deg) turns it. transform-style:preserve-3d makes children share 3D space.

style.css
.scene { perspective: 800px; }
.card-inner { transform-style: preserve-3d; transition: transform .6s ease; }
.card-front, .card-back { backface-visibility: hidden; position: absolute; inset: 0; }
.card-back  { transform: rotateY(180deg); }
.scene:hover .card-inner { transform: rotateY(180deg); }
✏️ Your Task

Build a flip card: scene (perspective) → card-inner (preserve-3d + transition) → front (normal) + back (rotateY 180deg). Hover scene to flip!

Phase 2 of 2
3D cube
📖 Concept

6 faces each positioned with rotate + translateZ. The cube has transform-style:preserve-3d and a spin animation.

style.css
.cube { transform-style: preserve-3d; animation: spin-cube 6s linear infinite; }
.face { position: absolute; backface-visibility: hidden; }
.front  { transform: translateZ(50px); }
.back   { transform: rotateY(180deg) translateZ(50px); }
.right  { transform: rotateY( 90deg) translateZ(50px); }
.left   { transform: rotateY(-90deg) translateZ(50px); }
@keyframes spin-cube { to { transform: rotateY(360deg) rotateX(15deg); } }
@media(prefers-reduced-motion:reduce){ .cube { animation:none; } }
✏️ Your Task

Build the spinning cube! Each face is absolute-positioned, rotated to face its direction, then pushed out with translateZ(50px).
