CSS Overflow

Control what happens when content is too big for its container using overflow. Work through 2 phases — complete each task before clicking Next Phase.

Phase 1
Overflow Values
💡 Concept

overflow values: visible (default — content spills), hidden (clips at border), scroll (always shows scrollbars), auto (adds scrollbars only when needed — usually best). Set independently: overflow-x and overflow-y. overflow-x: auto on a wrapper is the standard fix for wide tables on mobile.

style.css 
/* Comparison */
.ov-visible { overflow: visible; }  /* spills out */
.ov-hidden  { overflow: hidden;  }  /* clips content */
.ov-scroll  { overflow: scroll;  }  /* always scrollbars */
.ov-auto    { overflow: auto;    }  /* scrollbars when needed */

/* Horizontal scroll only */
.table-wrap { overflow-x: auto; overflow-y: visible; }

/* Scrollable area */
.chat { height: 300px; overflow-y: auto; scroll-behavior: smooth; }

Phase 2
Text Truncation and Practical Patterns
💡 Concept

Single-line truncation: white-space: nowrap; overflow: hidden; text-overflow: ellipsis;. Multi-line clamp: -webkit-line-clamp: 3; display: -webkit-box; -webkit-box-orient: vertical; overflow: hidden;. overflow: hidden on a parent also clips border-radius on children — that's how avatar circles work.

style.css 
/* Single-line ellipsis */
.truncate {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
  max-width: 250px;
}

/* Multi-line clamp */
.clamp-3 {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 3;
  overflow: hidden;
}

/* Circle avatar via overflow: hidden */
.avatar {
  width: 80px; height: 80px;
  border-radius: 50%;
  overflow: hidden;
}
.avatar img { width: 100%; height: 100%; object-fit: cover; }
