CSS Image Gallery

Build a responsive image gallery using CSS Grid and hover overlay effects. Work through 2 phases — complete each task before clicking Next Phase.

Phase 1
Responsive Grid Gallery
💡 Concept

CSS Grid is perfect for image galleries. grid-template-columns: repeat(auto-fill, minmax(200px, 1fr)) creates as many columns as fit, each at least 200px wide — fully responsive without media queries! Add gap for spacing. Set images to width: 100%; height: 200px; object-fit: cover; so they all show the same height regardless of the original image dimensions.

style.css 
/* Responsive grid gallery */
.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  gap: 16px;
}

/* Gallery images */
.gallery-item {
  border-radius: 12px;
  overflow: hidden;
  position: relative;
  cursor: pointer;
}

.gallery-item img {
  width: 100%;
  height: 220px;
  object-fit: cover;
  display: block;
  transition: transform .4s ease;
}

.gallery-item:hover img { transform: scale(1.06); }
✏️ Your Task

Create a grid gallery with 6 images. Use object-fit: cover so all images fill the same height. Add border-radius and a hover scale effect. The grid should automatically adjust columns based on viewport width — test by resizing your browser.

Phase 2
Lightbox-style Overlay
💡 Concept

Enhance the gallery with a hover overlay showing the image title and a view button. The overlay is position: absolute; inset: 0; with a gradient background, hidden by default (opacity: 0) and revealed on hover (opacity: 1). Use CSS transitions for smooth reveals. A caption at the bottom is a common design pattern.

style.css 
/* Hover overlay */
.gallery-item .overlay {
  position: absolute;
  inset: 0;
  background: linear-gradient(
    to top,
    rgba(2,132,199,.9) 0%,
    transparent 60%
  );
  display: flex;
  flex-direction: column;
  justify-content: flex-end;
  padding: 16px;
  opacity: 0;
  transition: opacity .3s;
}

.gallery-item:hover .overlay { opacity: 1; }

.overlay h3 { color: white; margin: 0 0 4px; font-size: 15px; }
.overlay p  { color: rgba(255,255,255,.8); font-size: 12px; margin: 0; }

/* Filter buttons */
.filter-btns { display: flex; gap: 8px; flex-wrap: wrap; margin-bottom: 20px; }
.filter-btn {
  padding: 8px 18px; border-radius: 100px; border: 1.5px solid #0284c7;
  color: #0284c7; background: transparent; cursor: pointer; font-size: 13px;
  font-weight: 700; transition: .15s;
}
.filter-btn.active, .filter-btn:hover { background: #0284c7; color: white; }
✏️ Your Task

Add a hover overlay with a gradient that goes from transparent at the top to semi-transparent blue at the bottom, with a white title at the bottom. This 'caption on hover' effect is used on photography portfolio sites.

Try the task first, then click to continue!
