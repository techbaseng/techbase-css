CSS How To — Three Ways to Add CSS

Master all three methods of adding CSS to HTML: inline, internal and external. Work through 2 phases — complete each task before clicking Next Phase.

Phase 1
Inline and Internal CSS
💡 Concept

Inline CSS uses the style attribute directly on an element: <p style="color: blue;">. It has the highest specificity — it overrides everything else. Use it only for quick one-off tests or generated content. Internal CSS goes in a <style> block inside <head>. It styles just that one page. Good for single-page projects or page-specific overrides.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>CSS Methods</title>

    <!-- INTERNAL CSS — styles this page only -->
    <style>
      body { font-family: Arial, sans-serif; padding: 30px; }
      h1   { color: #0284c7; }
      .box { border: 2px solid #0284c7; padding: 16px;
             border-radius: 10px; margin: 12px 0; }
    </style>
  </head>
  <body>
    <h1>CSS Methods</h1>

    <!-- INLINE CSS — overrides everything, use sparingly -->
    <p style="color: green; font-weight: bold;">
      This is inline CSS — colour and weight set directly.
    </p>

    <!-- Class from internal CSS -->
    <div class="box">
      This uses the .box class from internal CSS.
    </div>
  </body>
</html>

Phase 2
External CSS — The Professional Standard
💡 Concept

External CSS lives in a separate .css file. Link it with: <link rel="stylesheet" href="style.css"> in the <head>. This is how professional websites work — one CSS file can style hundreds of pages. Change one rule and every page updates. The CSS file has no HTML tags — just pure CSS rules. You can also import one CSS file into another with @import url('other.css');.

index.html + style.css 
<!-- index.html -->
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>External CSS</title>
    <!-- Link to external stylesheet -->
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <h1>Styled by External CSS!</h1>
    <p class="intro">This is the intro paragraph.</p>
    <p>This is a normal paragraph.</p>
  </body>
</html>

/* style.css — no HTML tags, just CSS! */
body {
  font-family: Arial, sans-serif;
  background: #f0f9ff;
  max-width: 800px;
  margin: 0 auto;
  padding: 30px;
}
h1    { color: #0284c7; }
p     { color: #334155; line-height: 1.8; }
.intro { font-size: 1.1rem; font-weight: 700; color: #0f172a; }
✏️ Your Task

🏗️ Build It!
My Three-Method Demo

Create two HTML pages that share one external style.css file — proving that one CSS file can style everything.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <!-- index.html — links to style.css below -->
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Home — My Styled Website</title>
    <style>
      /* ── PASTE THE STYLE.CSS CONTENT HERE TOO ── */
      /* (In real projects these would be two separate files) */
      * { box-sizing: border-box; }
      body { font-family: Arial, sans-serif; background: #f0f9ff;
             max-width: 800px; margin: 0 auto; padding: 30px; color: #0f172a; }
      nav  { background: #0284c7; padding: 12px 20px; border-radius: 10px;
             margin-bottom: 24px; }
      nav a { color: white; text-decoration: none; font-weight: bold; margin-right: 16px; }
      nav a:hover { text-decoration: underline; }
      h1   { color: #0284c7; font-size: 2rem; margin-bottom: 6px; }
      h2   { color: #0369a1; margin-top: 28px; }
      p    { color: #334155; line-height: 1.8; }
      .card { background: white; border: 1.5px solid #e2e8f0; border-radius: 12px;
              padding: 20px; margin: 14px 0; }
      .card h3 { color: #0284c7; margin: 0 0 8px; }
      .inline-demo { color: red; font-weight: bold; }
    </style>
  </head>
  <body>

    <!-- External CSS would be: <link rel="stylesheet" href="style.css"> -->

    <nav>
      <a href="index.html">Home</a>
      <a href="about.html">About</a>
    </nav>

    <h1>External CSS Demo</h1>
    <p>This page is styled by an external <code>style.css</code> file.
       Any page that links to the same file gets these styles automatically!</p>

    <h2>The Three Methods</h2>
    <div class="card">
      <h3>1. External CSS (Best)</h3>
      <p>Separate .css file linked with &lt;link rel="stylesheet"&gt;.
         One file styles many pages. Change once — updates everywhere.</p>
    </div>
    <div class="card">
      <h3>2. Internal CSS (Good for single pages)</h3>
      <p>&lt;style&gt; block in the &lt;head&gt;. Styles only that one page.</p>
    </div>
    <div class="card">
      <h3>3. Inline CSS (Use sparingly)</h3>
      <p>The <span class="inline-demo" style="color:red;">style</span>
         attribute on individual elements. Highest specificity, hardest to maintain.</p>
    </div>

    <p style="margin-top:24px; font-size:13px; color:#94a3b8;">
      📝 In a real project, save the CSS in style.css and link it with
      &lt;link rel="stylesheet" href="style.css"&gt;
    </p>

  </body>
</html>
