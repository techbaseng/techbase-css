Phase 1
Fixed and Percentage Dimensions
💡 Concept

width and height control element size. Pixels (px) are fixed — exact size regardless of screen. Percentages (%) are relative to the parent element — width: 50% is half the parent's width. A common pattern: give the body or a container a max-width then let children use percentages to fill it. height: auto (the default) lets the element grow to fit its content.

style.css 
/* Fixed pixel size */
.fixed-box { width: 300px; height: 150px; }

/* Percentage of parent */
.half-width { width: 50%; }
.full-width  { width: 100%; }

/* Container pattern */
.container {
  max-width: 960px;
  margin: 0 auto;
  width: 100%;
}

/* Height options */
.auto-height  { height: auto; }   /* grows with content */
.fixed-height { height: 200px; }  /* stays 200px always */

/* Square */
.square { width: 150px; height: 150px; }

Phase 2
Viewport Units and min/max
💡 Concept

Viewport units are relative to the browser window: vw (viewport width), vh (viewport height). 100vw = full screen width. Great for full-page hero sections: height: 100vh. min/max constraints: min-width, max-width, min-height, max-height set limits. Combine: width: 100%; max-width: 900px; is the most common responsive pattern.

style.css 
/* Full viewport hero */
.hero {
  width: 100vw;
  height: 100vh;
  background: linear-gradient(135deg, #0284c7, #0369a1);
}

/* Fluid but capped */
.content {
  width: 100%;
  max-width: 900px;
  min-width: 280px;
  margin: 0 auto;
}

/* Images that never overflow */
img { width: 100%; max-width: 100%; height: auto; }

/* Fluid heading */
h1 { font-size: clamp(1.5rem, 4vw, 3rem); }

🏗️ Build It!
My Sizing Demo Page

Build a page with a full-viewport hero, a max-width content area, and responsive-sized elements.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Sizing Demo</title>
    <style>
      *, *::before, *::after { box-sizing: border-box; margin: 0; padding: 0; }
      body { font-family: Arial, sans-serif; background: #f0f9ff; color: #0f172a; }
      .hero {
        min-height: 100vh;
        background: linear-gradient(135deg, #0284c7 0%, #0369a1 100%);
        display: flex; flex-direction: column;
        align-items: center; justify-content: center;
        text-align: center; padding: 40px 20px; color: white;
      }
      .hero h1 { font-size: clamp(2rem, 5vw, 3.5rem); font-weight: 900; margin-bottom: 16px; }
      .hero p  { font-size: clamp(1rem, 2vw, 1.2rem); opacity: .85; max-width: 500px; }
      .content { width: 100%; max-width: 860px; margin: 48px auto; padding: 0 24px; }
      h2 { color: #0284c7; margin-bottom: 16px; }
      .size-grid { display: flex; gap: 12px; flex-wrap: wrap; margin-bottom: 24px; }
      .size-box {
        background: #dbeafe; border: 2px solid #0284c7; padding: 10px;
        font-size: 12px; font-family: monospace; color: #0369a1; border-radius: 6px;
        display: flex; align-items: center; justify-content: center;
      }
      .vw50 { width: 50vw; background: #bae6fd; border-radius: 8px;
              padding: 14px; font-size: 13px; color: #0369a1; margin-bottom: 12px; }
      .vh30 { height: 30vh; background: #e0f2fe; border-radius: 8px;
              display: flex; align-items: center; justify-content: center;
              font-size: 13px; color: #0369a1; }
    </style>
  </head>
  <body>
    <div class="hero">
      <h1>CSS Sizing</h1>
      <p>This hero uses <code>min-height: 100vh</code> — full viewport height.</p>
    </div>
    <div class="content">
      <h2>Width: 25% + 50% + 25%</h2>
      <div class="size-grid">
        <div class="size-box" style="width:25%;height:80px">25%</div>
        <div class="size-box" style="width:50%;height:80px">50%</div>
        <div class="size-box" style="width:25%;height:80px">25%</div>
      </div>
      <h2>Viewport Units</h2>
      <div class="vw50">width: 50vw — half the viewport</div>
      <div class="vh30">height: 30vh</div>
    </div>
  </body>
</html>
