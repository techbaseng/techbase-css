Phase 1
Defining and Using Variables
💡 Concept

CSS variables (custom properties) store values for reuse. Define with two dashes: --colour: #0284c7. Use with var(--colour). Define on :root for global access, or on a selector to scope them. Variables inherit down the DOM — a child can use its parent's variables. Fall-back value: var(--colour, blue) uses blue if the variable isn't defined.

style.css 
:root {
  /* Colours */
  --primary:   #0284c7;
  --primary-d: #0369a1;
  --primary-p: #e0f2fe;
  --accent:    #ea4f21;
  --success:   #10b981;
  --danger:    #ef4444;

  /* Typography */
  --font-sans: 'Plus Jakarta Sans', Arial, sans-serif;
  --font-mono: 'JetBrains Mono', monospace;
  --text-sm:   0.875rem;
  --text-base: 1rem;
  --text-lg:   1.25rem;

  /* Spacing */
  --space-1: 4px;
  --space-2: 8px;
  --space-4: 16px;
  --space-6: 24px;
  --space-8: 32px;

  /* Radius */
  --radius-sm: 6px;
  --radius-md: 12px;
  --radius-lg: 18px;
  --radius-full: 100px;
}

/* Usage */
.btn {
  background: var(--primary);
  border-radius: var(--radius-md);
  padding: var(--space-2) var(--space-6);
  font-family: var(--font-sans);
  font-size: var(--text-sm);
}

Phase 2
Theming and JavaScript Integration
💡 Concept

Variables make theming trivial. A dark mode theme is just redefining the same variable names inside a [data-theme='dark'] selector. JavaScript can read and write CSS variables: el.style.setProperty('--primary', '#ea4f21'). This is how theme switchers work without reloading the page.

style.css 
:root { --bg: white; --text: #0f172a; --surface: #f8fafc; }

/* Dark theme — same variable names, different values */
[data-theme="dark"] {
  --bg:      #0f172a;
  --text:    #f1f5f9;
  --surface: #1e293b;
}

/* Components automatically adapt */
body    { background: var(--bg);      color: var(--text); }
.card   { background: var(--surface); border-color: var(--border); }

/* JS reads variables */
/* const primary = getComputedStyle(root).getPropertyValue('--primary') */

/* JS writes variables */
/* root.style.setProperty('--primary', '#ea4f21') */

/* Scoped variables — override in a component */
.hero {
  --text: white;           /* only white inside .hero */
  color: var(--text);
}
