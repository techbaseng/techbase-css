Phase 1 of 2
@font-face and Google Fonts
📖 Concept

@font-face { font-family:'Name'; src:url('font.woff2') format('woff2'); font-display:swap; }. WOFF2 = smallest format. font-display:swap shows fallback while loading. Google Fonts: paste their link tag. Always provide a fallback stack.

style.css
/* Google Fonts link in <head> */
/* <link href='https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@400;700;800&display=swap' rel='stylesheet'> */
body { font-family: 'Plus Jakarta Sans', -apple-system, Arial, sans-serif; }
h1   { font-weight: 800; }
code { font-family: 'JetBrains Mono', monospace; }
✏️ Your Task

Go to fonts.google.com, pick a display font + body font. Paste their link tags. Apply with fallback stacks. Check DevTools Network tab for font files loading.

Phase 2 of 2
Variable fonts
📖 Concept

Variable fonts contain the whole family in one file. font-weight becomes continuous: any value 100-900 works. System font stack = zero loading time.

style.css
@font-face { font-family:'Inter'; src:url('Inter-variable.woff2') format('woff2-variations'); font-weight:100 900; font-display:swap; }
.any-weight { font-weight: 523; } /* only possible with variable fonts! */
.system { font-family:-apple-system,BlinkMacSystemFont,'Segoe UI',Roboto,Arial,sans-serif; }
✏️ Your Task

If your Google Font is variable, set a weight range (100 900). Then use font-weight: 350 or 650 — values unavailable with regular fonts!
