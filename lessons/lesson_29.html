Phase 1
State Pseudo-classes
💡 Concept

State pseudo-classes respond to user interaction. :hover — mouse over. :focus — keyboard/click focus. :focus-visible — focus only for keyboard. :active — being clicked. :checked — checkbox or radio is ticked. :disabled — form element disabled. :valid / :invalid — HTML5 form validation state. :not(selector) — everything EXCEPT that selector.

style.css 
/* Hover */
.btn:hover { background: #0369a1; transform: translateY(-2px); }

/* Focus */
input:focus { border-color: #0284c7; box-shadow: 0 0 0 3px rgba(2,132,199,.25); }

/* Active */
.btn:active { transform: translateY(0); box-shadow: none; }

/* Checked */
input:checked + label { color: #10b981; font-weight: bold; }

/* Disabled */
input:disabled { opacity: .5; cursor: not-allowed; background: #f1f5f9; }

/* Valid / invalid */
input:valid   { border-color: #10b981; }
input:invalid { border-color: #ef4444; }

/* Not selector */
.btn:not(.primary) { background: transparent; color: #0284c7; }
li:not(:last-child) { border-bottom: 1px solid #e2e8f0; }

Phase 2
Structural Pseudo-classes
💡 Concept

Structural pseudo-classes select elements based on their position in the DOM. :first-child / :last-child. :nth-child(n) — every nth element (even, odd, 3n, 3n+1). :first-of-type / :last-of-type — first/last of a specific element type within its parent. :only-child — element that has no siblings.

style.css 
/* Position-based */
li:first-child  { font-weight: bold; color: #0284c7; }
li:last-child   { color: #94a3b8; font-style: italic; }
li:nth-child(2) { background: #f0f9ff; }

/* Pattern-based (n = counter) */
tr:nth-child(even) td { background: #f0f9ff; } /* zebra */
tr:nth-child(odd)  td { background: white; }
li:nth-child(3n)       { color: #0284c7; }   /* every 3rd */
li:nth-child(-n + 3)   { font-weight: bold; } /* first 3 */

/* Type-based */
p:first-of-type { font-size: 1.1rem; font-weight: 600; }
p:last-of-type  { color: #94a3b8; }

/* Empty element */
.tag:empty { display: none; }
✏️ Your Task

Apply :nth-child(even) zebra stripes to a table. Then use li:nth-child(-n+3) to bold the first three items in a list. Use li:first-child to give the first item a special badge.

    <style>
      *, *::before, *::after { box-sizing: border-box; }
      body { font-family: Arial, sans-serif; background: #f0f9ff;
             padding: 30px; max-width: 860px; margin: 0 auto; color: #0f172a; }
      h1 { color: #0284c7; margin-bottom: 6px; }
      h2 { color: #0369a1; margin: 28px 0 14px;
           border-bottom: 2px solid #bae6fd; padding-bottom: 6px; }
      .demo { background: white; border: 1.5px solid #bae6fd;
              border-radius: 12px; padding: 20px; margin-bottom: 14px; }
      /* Buttons */
      .btn { display: inline-block; padding: 10px 22px; border-radius: 9px;
             font-weight: 700; font-size: 14px; border: none; cursor: pointer;
             background: #0284c7; color: white; margin: 4px; transition: .2s; }
      .btn:hover   { background: #0369a1; transform: translateY(-2px); box-shadow: 0 4px 12px rgba(2,132,199,.3); }
      .btn:active  { transform: translateY(0); box-shadow: none; }
      .btn.outline { background: transparent; color: #0284c7; border: 2px solid #0284c7; }
      .btn.outline:hover { background: #0284c7; color: white; }
      /* Inputs */
      input[type="text"], input[type="email"] {
        width: 100%; padding: 10px 14px; border: 1.5px solid #cbd5e1;
        border-radius: 9px; font-size: 14px; outline: none; margin-bottom: 10px; transition: .2s;
      }
      input:focus   { border-color: #0284c7; box-shadow: 0 0 0 3px rgba(2,132,199,.2); }
      input:valid   { border-color: #10b981; }
      input:invalid { border-color: #ef4444; }
      input:disabled { opacity: .5; cursor: not-allowed; background: #f1f5f9; }
      input[type="checkbox"]:checked + label { color: #10b981; font-weight: bold; }
      /* Lists */
      .styled-list { list-style: none; padding: 0; }
      .styled-list li { padding: 10px 0; border-bottom: 1px solid #e2e8f0; font-size: 14px; }
      .styled-list li:first-child { font-weight: bold; color: #0284c7; }
      .styled-list li:last-child  { color: #94a3b8; font-style: italic; border: none; }
      .styled-list li:nth-child(-n+3) { background: #f0f9ff; padding-left: 8px; }
      /* Table */
      table { width: 100%; border-collapse: collapse; }
      th { background: #0284c7; color: white; padding: 10px 14px; text-align: left; }
      td { padding: 10px 14px; font-size: 14px; color: #334155; }
      tr:nth-child(even) td { background: #f0f9ff; }
      tr:nth-child(odd)  td { background: white; }
      tbody tr:hover td  { background: #dbeafe; }
      /* Not selector */
      .btn-group .btn:not(.primary) { background: transparent; color: #0284c7; border: 2px solid #0284c7; }
      .btn-group .btn:not(.primary):hover { background: #0284c7; color: white; }
    </style>
  </head>
