Phase 1
Responsive Navigation Patterns
💡 Concept

Three mobile nav patterns: (1) Hide links, show hamburger — toggle with JavaScript. (2) Horizontal scroll — links stay in a row but scroll if they overflow. (3) Priority+ — show important links, collapse the rest. The most common professional pattern uses a hamburger menu that reveals a full-screen or slide-in menu on mobile.

style.css 
/* Mobile: hamburger menu */
.nav-links { display: none; }
.hamburger { display: flex; flex-direction: column; gap: 5px; cursor: pointer; }
.hamburger span { height: 2px; width: 24px; background: white; border-radius: 2px; }

/* Mobile nav open state */
.nav-links.open {
  display: flex; flex-direction: column;
  position: fixed; inset: 0; background: #0f172a;
  justify-content: center; align-items: center;
  gap: 24px; z-index: 999; font-size: 1.5rem;
}

/* Tablet/desktop: horizontal nav */
@media (min-width: 768px) {
  .nav-links  { display: flex; gap: 4px; }
  .hamburger  { display: none; }
}

/* Horizontal-scroll nav (alternative) */
.scroll-nav { display: flex; overflow-x: auto;
              scrollbar-width: none; gap: 4px; }
.scroll-nav::-webkit-scrollbar { display: none; }
✏️ Your Task

Build a mobile hamburger menu that toggles visibility using JavaScript (classList.toggle('open')). Test on a small window. Then add a media query so the hamburger disappears and the horizontal nav appears at 768px and wider.

Phase 2
Responsive Tables and Images
💡 Concept

Tables on mobile: wrap in overflow-x: auto for horizontal scroll, or use CSS to stack cells vertically with display: block and data-label attributes. Images: max-width: 100%; height: auto; prevents overflow. object-fit: cover fills containers without distortion. The <picture> element serves different image sizes per breakpoint.

style.css 
/* Responsive table */
.table-wrap { overflow-x: auto; }

/* Stack table on mobile */
@media (max-width: 600px) {
  table, thead, tbody, th, td, tr { display: block; }
  thead { display: none; }          /* hide column headers */
  td {
    padding: 8px 8px 8px 50%;
    position: relative;
    border: none; border-bottom: 1px solid #e2e8f0;
  }
  td::before {
    content: attr(data-label); /* use the data-label attribute */
    position: absolute; left: 8px; top: 8px;
    font-weight: bold; color: #0284c7;
  }
}

/* Responsive images */
img { max-width: 100%; height: auto; }

/* Figure with responsive image */
figure { margin: 0; }
figure img { width: 100%; height: 200px; object-fit: cover; }

@media (min-width: 768px) { figure img { height: 350px; } }
✏️ Your Task

Add data-label attributes to every <td> in a table (e.g. data-label="Student"). Apply the mobile stacking CSS. Resize below 600px — the table should stack into a label+value list. This is used on real sites like banking and e-commerce.
