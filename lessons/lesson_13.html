CSS Outline

Phase 1
Outline vs Border
💡 Concept

outline draws a line outside the border but unlike border it takes up no space in the layout. Syntax: outline: 2px solid #0284c7. Add a gap with outline-offset: 4px. Styles: solid, dashed, dotted, double. Key difference from border: outline never affects the size or position of other elements.

style.css 
/* Outline styles */
.outline-solid  { outline: 2px solid  #0284c7; }
.outline-dashed { outline: 2px dashed #0284c7; }
.outline-dotted { outline: 3px dotted #0284c7; }
.outline-double { outline: 5px double #0284c7; }

/* With offset — gap between element and outline */
.offset { outline: 3px solid #0284c7; outline-offset: 6px; }

/* Outline doesn't push elements — border does */
.border-push { border: 3px solid #ea4f21; }  /* shifts layout */
.outline-nopush { outline: 3px solid #ea4f21; } /* no shift */

Phase 2
Outline for Keyboard Accessibility
💡 Concept

The most important use of outline is styling the focus state — the indicator for keyboard users. Never remove outlines without a replacement! :focus-visible shows the indicator only for keyboard navigation (not mouse clicks) — the modern best practice. Good focus styles have high contrast and an offset gap.

style.css 
/* Remove default, add custom */
:focus         { outline: none; }
:focus-visible {
  outline: 3px solid #0284c7;
  outline-offset: 3px;
  border-radius: 4px;
}

/* Great button focus */
.btn:focus-visible {
  outline: 3px solid #0284c7;
  outline-offset: 4px;
  box-shadow: 0 0 0 6px rgba(2,132,199,.2);
}

/* Input focus — glow effect */
input:focus {
  outline: none;
  border-color: #0284c7;
  box-shadow: 0 0 0 3px rgba(2,132,199,.25);
}
✏️ Your Task

Tab through your page using only the keyboard (press Tab). Every interactive element should have a visible focus indicator. Style :focus-visible on buttons and links to make them clearly visible. Test: can you navigate without a mouse?

My Accessible Focus Page

Build a form and navigation with beautiful, accessible focus styles using outline and focus-visible.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Outline and Focus</title>
    <style>
      *, *::before, *::after { box-sizing: border-box; }
      body { font-family: Arial, sans-serif; background: #f0f9ff;
             padding: 30px; max-width: 800px; margin: 0 auto; color: #0f172a; }
      h1 { color: #0284c7; margin-bottom: 6px; }
      h2 { color: #0369a1; margin: 28px 0 14px;
           border-bottom: 2px solid #bae6fd; padding-bottom: 6px; }
      .demo { display: flex; flex-wrap: wrap; gap: 16px; margin-bottom: 20px; }
      .od { padding: 14px 18px; background: white; font-size: 13px;
            font-family: monospace; color: #0369a1; border-radius: 4px; }
      .od1 { outline: 3px solid  #0284c7; }
      .od2 { outline: 3px dashed #ea4f21; }
      .od3 { outline: 3px dotted #10b981; }
      .od4 { outline: 5px double #7c3aed; }
      .od5 { outline: 3px solid  #0284c7; outline-offset: 8px; }
      :focus         { outline: none; }
      :focus-visible { outline: 3px solid #0284c7; outline-offset: 3px; border-radius: 4px; }
      nav { background: #0284c7; padding: 12px 20px; border-radius: 10px;
            margin-bottom: 28px; display: flex; gap: 6px; }
      nav a { color: white; text-decoration: none; font-weight: bold; padding: 8px 14px;
              border-radius: 8px; font-size: 14px; }
      nav a:hover { background: rgba(255,255,255,.2); }
      nav a:focus-visible { outline: 3px solid white; outline-offset: 2px; }
      .btn { display: inline-block; padding: 11px 22px; border-radius: 9px;
             font-size: 15px; font-weight: bold; cursor: pointer; border: none; margin: 4px; }
      .btn-p { background: #0284c7; color: white; }
      .btn-o { background: transparent; color: #0284c7; border: 2px solid #0284c7; }
      .btn:focus-visible { outline: 3px solid #0284c7; outline-offset: 4px;
                           box-shadow: 0 0 0 6px rgba(2,132,199,.15); }
      label { display: block; font-weight: 700; font-size: 13px; color: #475569; margin-bottom: 5px; }
      input { width: 100%; padding: 11px 14px; font-size: 14px; border: 1.5px solid #cbd5e1;
              border-radius: 9px; outline: none; font-family: Arial; margin-bottom: 14px; }
      input:focus { border-color: #0284c7; box-shadow: 0 0 0 3px rgba(2,132,199,.2); }
    </style>
  </head>
  <body>
    <nav>
      <a href="#">Home</a><a href="#">Courses</a><a href="#">Contact</a>
    </nav>
    <h1>Outline and Focus Accessibility</h1>
    <p>Press <kbd style="background:#0f172a;color:white;padding:2px 8px;border-radius:4px;font-size:12px;">Tab</kbd> to test keyboard navigation.</p>
    <h2>Outline Styles</h2>
    <div class="demo">
      <div class="od od1">solid</div>
      <div class="od od2">dashed</div>
      <div class="od od3">dotted</div>
      <div class="od od4">double</div>
      <div class="od od5">offset: 8px</div>
    </div>
    <h2>Button Focus States</h2>
    <button class="btn btn-p">Primary</button>
    <button class="btn btn-o">Outline</button>
    <h2>Input Focus</h2>
    <label for="n">Full Name</label>

    <label for="e">Email</label>
    <input id="e" type="email" placeholder="you@example.com">

  </body>
</html>
