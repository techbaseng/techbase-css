CSS Navigation Bar

Build professional horizontal and vertical navigation bars from scratch using CSS. Work through 2 phases — complete each task before clicking Next Phase.

Phase 1
Horizontal Navigation Bar
💡 Concept

The standard horizontal nav: start with a <ul>, reset list styles, make <li> elements display: inline-block or use Flexbox on the <ul>. Style <a> tags as blocks with padding so the whole area is clickable. Add hover states with :hover. Mark the current page with an .active class.

style.css 
/* Horizontal nav with flexbox */
.navbar {
  background: #0284c7;
  display: flex;
  align-items: center;
  padding: 0 24px;
  gap: 4px;
}

.navbar a {
  color: rgba(255,255,255,.85);
  text-decoration: none;
  font-weight: 600;
  font-size: 14px;
  padding: 18px 16px;
  border-radius: 6px;
  display: block;
  transition: background .15s, color .15s;
}

.navbar a:hover, .navbar a.active {
  background: rgba(255,255,255,.15);
  color: white;
}

/* Brand / logo on the left */
.nav-brand {
  font-weight: 800;
  font-size: 1.1rem;
  color: white;
  margin-right: auto; /* pushes links to the right */
}

Phase 2
Vertical Side Navigation
💡 Concept

Vertical navs are common for dashboards and admin panels. The pattern: fixed or sticky sidebar with a list of links. Each <a> is display: block with padding. Add icons using Bootstrap Icons alongside text. Group items with section headings. Add a bottom border between groups.

style.css 
/* Sidebar nav */
.sidebar {
  width: 240px;
  min-height: 100vh;
  background: #0f172a;
  padding: 20px 12px;
  position: fixed;
  top: 0; left: 0;
}

.sidebar .brand { color: white; font-weight: 800; padding: 8px 12px; margin-bottom: 20px; }

.nav-section { font-size: 11px; text-transform: uppercase;
               letter-spacing: .08em; color: #475569;
               padding: 6px 12px; margin-top: 16px; }

.sidebar a {
  display: flex; align-items: center; gap: 10px;
  color: #94a3b8; text-decoration: none; font-size: 14px;
  padding: 10px 12px; border-radius: 8px; font-weight: 500;
  transition: background .15s, color .15s;
}

.sidebar a:hover, .sidebar a.active {
  background: rgba(255,255,255,.08);
  color: white;
}

.sidebar a.active { color: #38bdf8; }
✏️ Your Task

Build a dark sidebar navigation with at least two sections (e.g. 'Main' and 'Settings'), each with three links. Add Bootstrap Icons beside each link name. Make one link active (highlighted in blue). Add hover effects.

Try the task first, then click to continue!

🏗️ Build It!
My Navigation Bar

Build a complete page layout with a top navigation bar and a sidebar navigation.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Navigation</title>
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css">
    <style>
      *, *::before, *::after { box-sizing: border-box; margin: 0; padding: 0; }
      body { font-family: Arial, sans-serif; background: #f0f9ff; color: #0f172a; }
      /* TOP NAV */
      .topnav { background: #0284c7; display: flex; align-items: center; padding: 0 28px; position: sticky; top: 0; z-index: 100; box-shadow: 0 2px 8px rgba(2,132,199,.3); }
      .nav-brand { font-weight: 800; font-size: 1.1rem; color: white; padding: 18px 0; margin-right: auto; }
      .nav-links { display: flex; gap: 4px; }
      .nav-links a { color: rgba(255,255,255,.85); text-decoration: none; font-weight: 600; font-size: 14px; padding: 18px 14px; display: block; border-radius: 6px; transition: .15s; }
      .nav-links a:hover, .nav-links a.active { background: rgba(255,255,255,.15); color: white; }
      /* LAYOUT */
      .layout { display: flex; min-height: calc(100vh - 56px); }
      /* SIDEBAR */
      .sidebar { width: 220px; background: #0f172a; flex-shrink: 0; padding: 20px 10px; }
      .side-brand { color: white; font-weight: 800; font-size: .95rem; padding: 6px 12px; margin-bottom: 16px; }
      .nav-sec { font-size: 10px; text-transform: uppercase; letter-spacing: .1em; color: #475569; padding: 6px 12px; margin: 14px 0 4px; }
      .sidebar a { display: flex; align-items: center; gap: 10px; color: #94a3b8; text-decoration: none; font-size: 13px; padding: 9px 12px; border-radius: 8px; font-weight: 500; transition: .15s; margin: 1px 0; }
      .sidebar a:hover   { background: rgba(255,255,255,.08); color: #e2e8f0; }
      .sidebar a.active  { background: rgba(56,189,248,.1); color: #38bdf8; }
      /* MAIN */
      .main { flex: 1; padding: 32px; }
      .main h1 { color: #0284c7; margin-bottom: 8px; }
      .main p  { color: #475569; line-height: 1.8; margin-bottom: 16px; }
      /* Cards */
      .cards { display: flex; gap: 16px; flex-wrap: wrap; }
      .card { flex: 1; min-width: 180px; background: white; border: 1.5px solid #bae6fd; border-radius: 14px; padding: 22px; }
      .card h3 { color: #0284c7; margin: 0 0 8px; font-size: 14px; }
      .card p  { color: #64748b; font-size: 13px; margin: 0; }
    </style>
  </head>
