👋 Welcome to Lesson 53

Position individual items with grid-column, grid-row and place-self

📚 2 phases 🏗️ Build: My Grid Item Dashboard
Phase 1 of 2
Explicit placement
📖 Concept

grid-column: 2/4 — from line 2 to 4. grid-column: span 2 — span 2 from current. grid-area: row-start/col-start/row-end/col-end.

style.css
.item { grid-column: 2 / 4; }        /* from line 2 to line 4 */
.wide { grid-column: span 2; }       /* span 2 columns */
.hero { grid-area: 1 / 1 / 2 / -1; } /* row 1, all columns */
✏️ Your Task

Create a 4-column grid. Place the first item at grid-column: 1/-1 (full width). Place another at grid-column: span 2; grid-row: span 2; for a big featured card.

Phase 2 of 2
Self-alignment
📖 Concept

place-self: center centres an item in its cell. align-self = vertical, justify-self = horizontal. Values: start, end, center, stretch.

style.css
.centre  { place-self: center; }
.top     { align-self: start; }
.stretch { place-self: stretch; } /* default */
✏️ Your Task

Create equal-height cards in a grid. Give each card display:flex;flex-direction:column and the footer margin-top:auto so it always pins to the bottom.
