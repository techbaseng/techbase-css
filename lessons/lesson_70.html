CSS Object Fit and clip-path

Control media containers and create shapes with object-fit and clip-path

📚 2 phases 🏗️ Build: My Object Fit and Shapes Demo
Phase 1 of 2
object-fit
📖 Concept

object-fit:fill (default — stretches), contain (whole image, may letterbox), cover (fills, no distortion — best for cards), none (original size). object-position sets the crop focal point.

style.css
.img-box { width:300px; height:200px; }
.img-box img { width:100%; height:100%; }
.cover   { object-fit: cover; }
.contain { object-fit: contain; }
.face    { object-fit: cover; object-position: top center; }
✏️ Your Task

Create 4 equal boxes with the same image. Apply fill, contain, cover, scale-down. Notice cover is almost always what you want for card thumbnails.

Phase 2 of 2
clip-path shapes
📖 Concept

circle(50%), ellipse(), polygon(x y,...). Combine with transition for morphing: circle ↔ square. Use clippy.abhimanyu.io to generate values visually.

style.css
.circle   { clip-path: circle(50%); }
.triangle { clip-path: polygon(50% 0%, 0% 100%, 100% 100%); }
.hexagon  { clip-path: polygon(25% 0%,75% 0%,100% 50%,75% 100%,25% 100%,0% 50%); }
.morph { clip-path: polygon(25% 0%,75% 0%,100% 50%,75% 100%,25% 100%,0% 50%); transition: clip-path .4s ease; }
.morph:hover { clip-path: circle(50%); }
✏️ Your Task

Apply hexagon clip-path to an image. On hover transition to circle(50%). This is shape morphing — one clip-path to another!
