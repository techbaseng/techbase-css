Build hover tooltips using position, pseudo-elements and transitions

📚 2 phases 🏗️ Build: My CSS Tooltip Library
Phase 1 of 2
Basic tooltip pattern
📖 Concept

Trigger: position: relative. Tooltip: absolutely positioned ::before using content: attr(data-tip). Hidden by default (opacity:0), shown on hover. Arrow: ::after using border trick.

style.css
[data-tip] { position: relative; }
[data-tip]::before { content: attr(data-tip); position: absolute; bottom: calc(100% + 8px); left: 50%; transform: translateX(-50%); background: #0f172a; color: white; font-size: 12px; padding: 6px 12px; border-radius: 7px; white-space: nowrap; opacity: 0; pointer-events: none; transition: opacity .2s; z-index: 100; }
[data-tip]::after  { content: ''; position: absolute; bottom: calc(100% + 2px); left: 50%; transform: translateX(-50%); border: 6px solid transparent; border-top-color: #0f172a; opacity: 0; transition: opacity .2s; }
[data-tip]:hover::before, [data-tip]:hover::after { opacity: 1; }
✏️ Your Task

Add data-tip='Hello!' to a button. Apply the CSS. The tooltip should appear above on hover with a downward arrow.

Phase 2 of 2
Directional variants
📖 Concept

Change the position properties for 4 directions. Bottom: top: calc(100% + 8px) + flip arrow. Right: left: calc(100% + 8px). Left: right: calc(100% + 8px).

style.css
[data-tip].tip-bottom::before { top: calc(100% + 8px); bottom: auto; }
[data-tip].tip-bottom::after  { top: calc(100% + 2px); bottom: auto; border-top-color: transparent; border-bottom-color: #0f172a; }
[data-tip].tip-blue::before   { background: #0284c7; }
[data-tip].tip-blue::after    { border-top-color: #0284c7; }
✏️ Your Task

Create 4 buttons: one tooltip each direction (top, bottom, left, right). Add colour variants (blue, green, orange).
