CSS Combinators

Phase 1
Descendant, Child and Adjacent
💡 Concept

CSS combinators select elements based on their HTML relationship. Descendant div p — any p inside a div at any depth. Child div > p — only DIRECT children. Adjacent sibling h2 + p — the first p immediately after an h2. General sibling h2 ~ p — ALL p elements after an h2 at the same level.

style.css 
/* Descendant — any depth */
.card p { color: #475569; }  /* all p inside .card */

/* Child — direct only */
.card > h3 { color: #0284c7; margin-top: 0; }

/* Adjacent sibling — immediately after */
h2 + p {
  font-size: 1.05rem;
  font-weight: 600;
  color: #0284c7;
}

/* General sibling — all after */
h2 ~ p { color: #334155; }

/* Practical: style first paragraph after a heading differently */
h1 + p { font-size: 1.1rem; color: #475569; }

/* Style direct list items only (not nested) */
ul > li { border-bottom: 1px solid #e2e8f0; }

Phase 2
Practical Combinator Patterns
💡 Concept

Combinators are powerful for styling without adding extra classes. Common patterns: style the first paragraph after every heading differently, alternate table rows without JavaScript, style form inputs based on their label, apply margin only between adjacent siblings (the 'lobotomised owl' * + *), and create pure CSS nested nav styling.

style.css 
/* The 'owl' — margin only between siblings */
.stack > * + * { margin-top: 16px; }
/* Instead of margin on every element, only add it
   when an element follows another element */

/* Table zebra without nth-child */
/* (nth-child is better but combinators show the concept) */

/* Style form labels that follow checked checkboxes */
input[type="checkbox"]:checked + label {
  color: #10b981;
  font-weight: bold;
}

/* Nav — style links inside nav only */
nav a { color: white; text-decoration: none; }
nav a:hover { text-decoration: underline; }

/* Style .card > .badge only (not nested badges) */
.card > .badge { position: absolute; top: -8px; right: -8px; }

Use the > * + * (owl) pattern to add spacing between children: .stack > * + * { margin-top: 20px; }. Apply it to a container with several divs — spacing appears between them automatically without adding margin to the first element!

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Combinators</title>
    <style>
      *, *::before, *::after { box-sizing: border-box; }
      body { font-family: Arial, sans-serif; background: #f0f9ff;
             padding: 30px; max-width: 860px; margin: 0 auto; color: #0f172a; }
      h1 { color: #0284c7; margin-bottom: 6px; }
      h2 { color: #0369a1; margin: 28px 0 14px;
           border-bottom: 2px solid #bae6fd; padding-bottom: 6px; }
      .demo { background: white; border: 1.5px solid #bae6fd;
              border-radius: 12px; padding: 20px; margin-bottom: 14px; }
      code { background: #dbeafe; color: #1e40af; padding: 2px 6px;
             border-radius: 4px; font-family: monospace; font-size: 13px; }

      /* Descendant: any p inside .desc-demo */
      .desc-demo p { color: #0284c7; font-style: italic; }
      /* Child: only direct h3 */
      .child-demo > h3 { color: #10b981; font-size: 1rem; margin: 0 0 8px; }
      .child-demo .nested h3 { color: #94a3b8; } /* nested — NOT targeted */
      /* Adjacent sibling */
      .adj-demo h3 + p { color: #ea4f21; font-weight: bold; }
      /* General sibling */
      .gen-demo h3 ~ p  { color: #7c3aed; }

      /* Owl spacing pattern */
      .owl-demo > * + * { margin-top: 16px; }
      .owl-item { background: #dbeafe; border-radius: 8px; padding: 12px 16px;
                  color: #1e40af; font-size: 13px; }

      /* Checkbox + label */
      input[type="checkbox"] { margin-right: 8px; }
      input[type="checkbox"]:checked + label { color: #10b981; font-weight: bold; }
    </style>
  </head>
  <body>
    <h1>CSS Combinators</h1>

    <h2><code>div p</code> — Descendant (any depth)</h2>
    <div class="demo desc-demo">
      <p>This p is a direct child — styled blue italic.</p>
      <div><p>This nested p is also styled — descendant selector reaches any depth.</p></div>
    </div>

    <h2><code>div > h3</code> — Child (direct only)</h2>
    <div class="demo child-demo">
      <h3>Direct child h3 — styled green ✓</h3>
      <div class="nested"><h3>Nested h3 — grey, NOT targeted ✗</h3></div>
    </div>

    <h2><code>h3 + p</code> — Adjacent Sibling (first immediately after)</h2>
    <div class="demo adj-demo">
      <h3>Heading</h3>
      <p>First p after h3 — orange bold ✓</p>
      <p>Second p — normal style ✗</p>
    </div>

    <h2><code>h3 ~ p</code> — General Sibling (all after)</h2>
    <div class="demo gen-demo">
      <h3>Heading</h3>
      <p>First p after h3 — purple ✓</p>
      <p>Second p after h3 — also purple ✓</p>
      <p>Third p — still purple ✓</p>
    </div>

    <h2>Owl Pattern — <code>.stack > * + *</code></h2>
    <div class="demo owl-demo">
      <div class="owl-item">First — no top margin</div>
      <div class="owl-item">Second — top margin added automatically</div>
      <div class="owl-item">Third — top margin added automatically</div>
      <div class="owl-item">Fourth — top margin added automatically</div>
    </div>

    <h2>Checkbox + Label</h2>
    <div class="demo">
      <p><input type="checkbox" id="c1"><label for="c1">Check me — label turns green when checked!</label></p>
      <p><input type="checkbox" id="c2"><label for="c2">Another checkbox</label></p>
    </div>
  </body>
</html>
