Phase 1
Padding Shorthand and Individual Sides
💡 Concept

padding adds space inside an element — between its content and its border. The syntax is identical to margin: 1, 2, 3, or 4 values going clockwise (top, right, bottom, left). Unlike margin, padding cannot be negative. Padding is inside the background colour, so it shows the element's background — margin is outside and shows the parent's background.

style.css 
/* All sides equal */
.p-all  { padding: 20px; }

/* Vertical | Horizontal */
.p-vh   { padding: 12px 24px; }

/* Clockwise: top right bottom left */
.p-4    { padding: 10px 20px 15px 30px; }

/* Individual sides */
.pt { padding-top: 24px; }
.pr { padding-right: 16px; }
.pb { padding-bottom: 24px; }
.pl { padding-left: 16px; }

/* Useful patterns */
.btn {
  padding: 12px 24px;  /* more left/right than top/bottom */
  display: inline-block;
}

.card {
  padding: 24px;       /* generous internal spacing */
}

.code-block {
  padding: 16px 20px;  /* slightly more horizontal */
  font-family: monospace;
}

Phase 2
Padding and the Box Model
💡 Concept

By default, width sets the content width only. If you add padding: 20px to an element with width: 200px, the total rendered width becomes 240px (200 + 20 + 20). This surprises beginners! The fix: box-sizing: border-box makes the width include padding and border, so width: 200px with padding: 20px stays at exactly 200px total. Always add * { box-sizing: border-box; } at the top of your stylesheet.

style.css 
/* ── Without border-box (default content-box) ── */
.content-box {
  box-sizing: content-box; /* default */
  width: 200px;
  padding: 20px;
  border: 2px solid #0284c7;
  /* TOTAL width = 200 + 20+20 + 2+2 = 244px! */
}

/* ── With border-box (recommended) ── */
.border-box {
  box-sizing: border-box; /* padding + border INCLUDED in width */
  width: 200px;
  padding: 20px;
  border: 2px solid #ea4f21;
  /* TOTAL width = exactly 200px */
}

/* BEST PRACTICE — apply to everything */
*, *::before, *::after {
  box-sizing: border-box;
}
