Phase 1
Colour Names and Hex Codes
💡 Concept

CSS supports 140 named colours like red, coral, steelblue. Hex codes use # and 6 hex digits (0-9, A-F): first two = red, middle two = green, last two = blue. #ff0000 = red, #00ff00 = green, #0000ff = blue, #000000 = black, #ffffff = white. Short hex: #09c = #0099cc. CSS also has currentColor (inherits the element's text colour) and transparent.

style.css 
/* Named colours */
.red-box   { background-color: red; }
.coral-box { background-color: coral; }
.navy-box  { background-color: navy; }

/* Hex codes */
.hex-orange { background-color: #ea4f21; color: white; }
.hex-blue   { background-color: #0284c7; color: white; }
.hex-green  { background-color: #10b981; color: white; }

/* Short hex (3 digits) */
.hex-short  { background-color: #09c; color: white; }

/* currentColor — inherits the text colour */
.border-match {
  color: #0284c7;
  border: 2px solid currentColor; /* same blue as the text */
}

/* transparent */
.ghost-button {
  background: transparent;
  border: 2px solid #0284c7;
  color: #0284c7;
}

Phase 2
RGB, RGBA, HSL and HSLA
💡 Concept

rgb(r, g, b) — values 0–255 per channel. rgba(r, g, b, a) — adds alpha transparency (0=invisible, 1=solid). hsl(h, s%, l%) — Hue (0-360° colour wheel), Saturation (0%=grey, 100%=vivid), Lightness (0%=black, 50%=normal, 100%=white). HSL is intuitive for creating colour variations: same hue, adjust lightness for shades. New CSS: color(display-p3 0 0.5 1) for wider gamut, oklch() for perceptually uniform colours.

style.css 
/* RGB — three channels 0-255 */
.rgb-red   { background: rgb(234, 79, 33);  color: white; }
.rgb-blue  { background: rgb(2, 132, 199);  color: white; }
.rgb-green { background: rgb(16, 185, 129); color: white; }

/* RGBA — with transparency */
.overlay {
  background: rgba(2, 132, 199, 0.15); /* 15% opacity blue */
  border: 1px solid rgba(2, 132, 199, 0.4);
}

/* HSL — hue, saturation, lightness */
.hsl-primary { background: hsl(201, 98%, 39%); color: white; }
.hsl-light   { background: hsl(201, 98%, 90%); color: #0f172a; }
.hsl-dark    { background: hsl(201, 98%, 20%); color: white; }

/* HSLA — with transparency */
.card-tint { background: hsla(201, 98%, 39%, 0.1); }

/* CSS variables for a colour system */
:root {
  --primary:      hsl(201, 98%, 39%);
  --primary-pale: hsl(201, 98%, 90%);
  --primary-dark: hsl(201, 98%, 20%);
}
