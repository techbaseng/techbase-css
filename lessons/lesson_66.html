Translate, rotate, scale and skew elements without affecting layout

📚 2 phases 🏗️ Build: My 2D Transform Gallery
Phase 1 of 2
translate, rotate and scale
📖 Concept

transform moves elements visually WITHOUT affecting layout flow. translate(x,y) moves, rotate(deg) spins, scale(n) resizes, scaleX(-1) mirrors. Chain: rotate(30deg) scale(1.1). Order matters — applied right to left.

style.css
.move   { transform: translateX(50px); }
.rotate { transform: rotate(45deg); }
.big    { transform: scale(1.5); }
.mirror { transform: scaleX(-1); }
.combo  { transform: rotate(15deg) scale(1.1); }
.card:hover { transform: translateY(-8px) scale(1.02); transition: transform .25s ease; }
✏️ Your Task

Show 5 boxes: translate, rotate 45deg, scale 1.5, scaleX(-1) mirror, and rotate+scale combo. Add hover transitions so they animate smoothly.

Phase 2 of 2
skew and diagonal sections
📖 Concept

skewX(20deg) slants horizontally. Diagonal sections: skewY(-3deg) on wrapper, counter-rotate content with skewY(3deg) so text stays straight.

style.css
.skew-x { transform: skewX(20deg); }
.diagonal { transform: skewY(-3deg); overflow: hidden; }
.diagonal .inner { transform: skewY(3deg); } /* un-skew text */
✏️ Your Task

Create a diagonal section using skewY(-3deg) on the outer div. Counter-rotate the inner content with skewY(3deg). This is a popular landing-page design trick!
