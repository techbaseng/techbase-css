CSS Pseudo-elements

Phase 1
::before and ::after
💡 Concept

Pseudo-elements create virtual elements not in the HTML. ::before inserts before the element's content; ::after inserts after. Both require content: '' (even if empty). They inherit the parent's styles and can be positioned absolutely. Common uses: decorative quotes, icons, underline animations, badges, clearfix, and tooltips — all without adding HTML.

style.css 
/* Quotation marks */
blockquote::before { content: '"'; font-size: 4rem; color: #0284c7; line-height: 0; }
blockquote::after  { content: '"'; font-size: 4rem; color: #0284c7; line-height: 0; }

/* Animated underline */
.link::after {
  content: '';
  position: absolute;
  width: 0; height: 2px; background: #0284c7;
  bottom: -2px; left: 0; transition: width .3s;
}
.link:hover::after { width: 100%; }

/* Badge / label */
.required::after {
  content: ' *';
  color: #ef4444;
  font-weight: bold;
}

/* Decorative bullet */
.fancy-list li::before {
  content: '→';
  color: #0284c7;
  font-weight: bold;
  margin-right: 8px;
}

/* Clearfix */
.clearfix::after { content: ''; display: block; clear: both; }

Phase 2
::first-line, ::first-letter, ::selection and ::placeholder
💡 Concept

::first-line styles only the first line of a paragraph (adjusts automatically as width changes). ::first-letter styles just the first character — used for drop caps. ::selection styles highlighted text. ::placeholder styles the placeholder text in inputs.

style.css 
/* First line of an article */
.article p::first-line {
  font-weight: bold;
  color: #0284c7;
}

/* Drop cap */
.article p::first-letter {
  font-size: 3.5rem;
  font-weight: 900;
  float: left;
  line-height: 1;
  margin: 0 8px -4px 0;
  color: #0284c7;
}

/* Text selection colour */
::selection {
  background: #bae6fd;
  color: #0f172a;
}

/* Input placeholder */
input::placeholder {
  color: #94a3b8;
  font-style: italic;
  font-size: .9em;
}
✏️ Your Task

    <style>
      *, *::before, *::after { box-sizing: border-box; }
      body { font-family: Georgia, serif; background: #f0f9ff;
             padding: 30px; max-width: 820px; margin: 0 auto; color: #0f172a; }
      h1 { font-family: Arial; color: #0284c7; margin-bottom: 6px; font-size: 2rem; }
      h2 { font-family: Arial; color: #0369a1; margin: 28px 0 14px;
           border-bottom: 2px solid #bae6fd; padding-bottom: 6px; }
      /* Selection */
      ::selection { background: #bae6fd; color: #0f172a; }
      /* Blockquote with ::before ::after */
      blockquote {
        position: relative; margin: 20px 0;
        padding: 16px 28px; background: white;
        border-radius: 12px; border-left: 4px solid #0284c7;
        font-style: italic; color: #334155; font-size: 1.05rem;
      }
      blockquote::before { content: 'C'; position: absolute; top: -10px; left: 12px;
                           font-size: 4rem; color: #0284c7; line-height: 1; font-family: Georgia; }
      /* Drop cap */
      .dropcap::first-letter {
        font-size: 3.5rem; font-weight: 900; float: left;
        line-height: 1; margin: 0 8px -4px 0; color: #0284c7; font-family: Arial;
      }
      .dropcap::first-line { font-weight: 600; color: #0369a1; }
      /* Fancy list */
      .fancy-list { list-style: none; padding: 0; }
      .fancy-list li { padding: 10px 0; border-bottom: 1px solid #e2e8f0;
                       font-family: Arial; font-size: 14px; }
      .fancy-list li::before { content: '→ '; color: #0284c7; font-weight: bold; }
      /* Required label */
      .req::after { content: ' *'; color: #ef4444; font-weight: bold; }
      /* Animated underline link */
      .ul-link { position: relative; text-decoration: none; color: #0284c7;
                 font-family: Arial; font-weight: 600; }
      .ul-link::after { content: ''; position: absolute; width: 0; height: 2px;
                        background: #0284c7; bottom: -2px; left: 0; transition: width .3s; }
      .ul-link:hover::after { width: 100%; }
      /* Placeholder */
      input::placeholder { color: #94a3b8; font-style: italic; }
      input { width: 100%; padding: 10px 14px; border: 1.5px solid #cbd5e1;
              border-radius: 9px; font-size: 14px; outline: none; margin-top: 8px; }
      input:focus { border-color: #0284c7; }
    </style>
  </head>
