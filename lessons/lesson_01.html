Phase 1
What Is CSS?
💡 Concept

CSS stands for Cascading Style Sheets. While HTML provides the structure (the bones), CSS provides the appearance (the skin). Without CSS, every website would look the same — plain black text on a white background. CSS controls colours, fonts, spacing, layout and animations. The word cascading means styles flow down from parent elements to children, and when two rules conflict, specific rules win.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>CSS Introduction</title>
    <style>
      /* This is a CSS comment */
      body {
        background-color: #f0f9ff;
        font-family: Arial, sans-serif;
        color: #0f172a;
      }
      h1 { color: #0284c7; }
      p  { font-size: 18px; line-height: 1.8; }
    </style>
  </head>
  <body>
    <h1>Hello, CSS!</h1>
    <p>CSS makes this page look beautiful.</p>
    <p>Try changing the color values and font-size!</p>
  </body>
</html>

Phase 2
CSS History and the Browser
💡 Concept

CSS was first proposed by Håkon Wium Lie in 1994 and became a W3C standard in 1996. Today we use CSS3, which adds animations, gradients, variables and much more. The browser reads your HTML first, then reads your CSS and applies the styles. This two-step process is called rendering. DevTools (F12) lets you inspect and change CSS live in the browser — a skill every developer uses every single day.

🏗️ Build It!
My First Styled Page

Build an HTML page that uses CSS to set background colour, font, text colour, and line height.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Styled Page</title>
    <style>
      /* ===== GLOBAL STYLES ===== */
      body {
        background-color: #f0f9ff;
        font-family: Arial, sans-serif;
        color: #0f172a;
        max-width: 750px;
        margin: 0 auto;
        padding: 40px 30px;
      }

      /* ===== HEADINGS ===== */
      h1 {
        color: #0284c7;
        font-size: 2.2rem;
        margin-bottom: 8px;
      }
      h2 {
        color: #0369a1;
        font-size: 1.3rem;
        margin-top: 28px;
      }

      /* ===== PARAGRAPHS ===== */
      p {
        font-size: 16px;
        line-height: 1.8;
        color: #334155;
      }

      /* ===== HIGHLIGHT BOX ===== */
      .highlight {
        background-color: #e0f2fe;
        border-left: 4px solid #0284c7;
        padding: 14px 18px;
        border-radius: 0 8px 8px 0;
        margin: 20px 0;
      }
    </style>
  </head>
  <body>

    <h1>Welcome to CSS! 🎨</h1>
    <p>This is my first page styled with CSS. CSS stands for
       <strong>Cascading Style Sheets</strong> and it controls
       how HTML looks in the browser.</p>

    <div class="highlight">
      <p>💡 <strong>Key fact:</strong> Without CSS, every website
         would look like a plain text document. CSS adds colour,
         layout, fonts and animations!</p>
    </div>

    <h2>What CSS Controls</h2>
    <p>CSS controls: colours, fonts, sizes, spacing, borders,
       backgrounds, animations and layout. Everything visual
       on a webpage is styled with CSS.</p>

    <h2>My First CSS Rules</h2>
    <p>In the &lt;style&gt; block above, I wrote CSS rules for
       body, h1, h2, p, and a special .highlight class.
       Try changing the values and see what happens!</p>

  </body>
</html>
