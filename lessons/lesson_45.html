CSS Media Queries

Make your pages adapt to any screen size using @media rules and breakpoints. Work through 2 phases — complete each task before clicking Next Phase.

Phase 1
Media Query Syntax and Breakpoints
💡 Concept

@media (condition) { rules }. Common conditions: max-width: 768px (tablet and below), min-width: 768px (tablet and above). Mobile-first approach: write base styles for mobile, add min-width queries for larger screens. Standard breakpoints: 480px (phone), 768px (tablet), 1024px (laptop), 1280px (desktop). Media type: @media screen and (max-width: 768px).

style.css 
/* Mobile-first: base = mobile */
.container { padding: 16px; }
.card { width: 100%; }
nav  { flex-direction: column; }

/* Tablet — 768px and up */
@media (min-width: 768px) {
  .container { padding: 28px; }
  .card { width: calc(50% - 8px); }
  nav  { flex-direction: row; }
}

/* Desktop — 1024px and up */
@media (min-width: 1024px) {
  .container { max-width: 1100px; margin: 0 auto; padding: 40px; }
  .card { width: calc(33.33% - 11px); }
}

/* Desktop-first approach (alternative) */
.card { width: 33.33%; }
@media (max-width: 1024px) { .card { width: 50%; } }
@media (max-width: 768px)  { .card { width: 100%; } }
✏️ Your Task

Write a mobile-first stylesheet: base styles for one column, then add a 768px breakpoint for two columns, and a 1024px breakpoint for three columns. Resize the browser to see the layout shift between one, two and three columns.

Phase 2
Media Features Beyond Width
💡 Concept

Media queries can target more than screen width: prefers-color-scheme: dark (user's OS dark mode), prefers-reduced-motion: reduce (user has motion sensitivity), orientation: landscape (device is horizontal), print (print stylesheet). Always respect prefers-reduced-motion — some users get dizzy from animations.

style.css 
/* Dark mode — OS-level preference */
@media (prefers-color-scheme: dark) {
  :root { --bg: #0f172a; --text: #f1f5f9; }
  body  { background: var(--bg); color: var(--text); }
}

/* Reduced motion — accessibility */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    transition-duration: .01ms !important;
  }
}

/* Landscape phone */
@media (orientation: landscape) and (max-height: 500px) {
  .hero { min-height: auto; padding: 40px 0; }
}

/* Print */
@media print {
  .navbar, .sidebar, .cookie-banner { display: none; }
  body { font-size: 12pt; color: black; background: white; }
  a::after { content: ' (' attr(href) ')'; }
}
✏️ Your Task

Add a @media (prefers-color-scheme: dark) block to your CSS. Open your OS settings, switch to dark mode, and reload the page — it should automatically switch! Also add @media (prefers-reduced-motion: reduce) { * { transition: none !important; } } for accessibility.

Try the task first, then click to continue!

🏗️ Build It!
My Responsive Layout

Build a fully responsive page with mobile/tablet/desktop breakpoints and dark mode support.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Media Queries</title>
    <style>
      :root { --primary: #0284c7; --bg: #f0f9ff; --surface: white; --text: #0f172a; --muted: #64748b; --border: #e2e8f0; }
      @media (prefers-color-scheme: dark) {
        :root { --bg: #0f172a; --surface: #1e293b; --text: #f1f5f9; --muted: #94a3b8; --border: #334155; }
      }
      @media (prefers-reduced-motion: reduce) {
        *, *::before, *::after { animation: none !important; transition: none !important; }
      }
      *, *::before, *::after { box-sizing: border-box; margin: 0; padding: 0; }
      body { font-family: Arial, sans-serif; background: var(--bg); color: var(--text); transition: background .3s, color .3s; }
      /* Mobile-first nav */
      .navbar { background: var(--primary); padding: 14px 20px; }
      .nav-inner { display: flex; flex-direction: column; gap: 8px; max-width: 1100px; margin: 0 auto; }
      .brand  { color: white; font-weight: 800; font-size: 1.05rem; }
      .nav-links { display: none; }
      @media (min-width: 640px) {
        .nav-inner { flex-direction: row; align-items: center; }
        .nav-links { display: flex; gap: 4px; margin-left: auto; }
        .nav-links a { color: rgba(255,255,255,.85); text-decoration: none; font-weight: 600; font-size: 13px; padding: 7px 12px; border-radius: 7px; }
        .nav-links a:hover { background: rgba(255,255,255,.15); color: white; }
      }
      /* Hero */
      .hero { padding: 48px 20px; text-align: center; background: linear-gradient(135deg, var(--primary), #0369a1); color: white; }
      .hero h1 { font-size: clamp(1.8rem, 5vw, 3rem); font-weight: 800; margin-bottom: 12px; }
      .hero p  { opacity: .85; font-size: clamp(.95rem, 2vw, 1.1rem); max-width: 500px; margin: 0 auto 20px; }
      .hero .badge { display: inline-block; background: rgba(255,255,255,.15); border: 1px solid rgba(255,255,255,.3); border-radius: 100px; padding: 5px 14px; font-size: 12px; font-weight: 700; }
      /* Content */
      .content { max-width: 1100px; margin: 0 auto; padding: 32px 20px; }
      .sec-h { color: var(--primary); font-size: 1.4rem; margin-bottom: 16px; }
      /* Card grid — mobile first */
      .cards { display: flex; flex-direction: column; gap: 16px; }
      .card { background: var(--surface); border: 1.5px solid var(--border); border-radius: 14px; padding: 22px; }
      .card h3 { color: var(--primary); margin: 0 0 8px; font-size: 15px; }
      .card p  { color: var(--muted); font-size: 13px; line-height: 1.7; margin: 0; }
      /* Tablet — 2 columns */
      @media (min-width: 640px) {
        .cards { flex-direction: row; flex-wrap: wrap; }
        .card  { flex: 1 1 calc(50% - 8px); }
      }
      /* Desktop — 3 columns */
      @media (min-width: 1024px) {
        .card { flex: 1 1 calc(33.33% - 11px); }
      }
      /* Breakpoint indicator */
      .bp { position: fixed; bottom: 16px; right: 16px; background: var(--primary); color: white; padding: 6px 14px; border-radius: 100px; font-size: 12px; font-weight: 700; }
      .bp::before { content: "📱 Mobile"; }
      @media (min-width: 640px)  { .bp::before { content: "📱 → Tablet 640+"; } }
      @media (min-width: 1024px) { .bp::before { content: "🖥️ Desktop 1024+"; } }
      /* Print */
      @media print {
        .navbar, .bp { display: none; }
        body { color: black; background: white; }
      }
    </style>
  </head>
  <body>
    <nav class="navbar">
      <div class="nav-inner">
        <span class="brand">⚡ Techbase</span>
        <div class="nav-links">
          <a href="#">Home</a><a href="#">Courses</a><a href="#">About</a>
        </div>
      </div>
    </nav>
    <div class="hero">
      <span class="badge">📱 Resize the browser!</span>
      <h1>Responsive Design</h1>
      <p>This page uses mobile-first media queries and automatically switches to dark mode based on your OS preference.</p>
    </div>
    <div class="content">
      <h2 class="sec-h">Responsive Cards</h2>
      <div class="cards">
        <div class="card"><h3>📱 Mobile</h3><p>Single column. Full-width cards. Compact navigation. Base styles — no media query needed.</p></div>
        <div class="card"><h3>📟 Tablet 640px+</h3><p>Two-column card grid. Navigation links appear. More breathing room.</p></div>
        <div class="card"><h3>🖥️ Desktop 1024px+</h3><p>Three-column layout. Full navigation. Max-width container centred.</p></div>
        <div class="card"><h3>🌙 Dark Mode</h3><p>@media (prefers-color-scheme: dark) — detected from your OS settings automatically.</p></div>
        <div class="card"><h3>♿ Motion</h3><p>@media (prefers-reduced-motion) — disables animations for users who need it.</p></div>
        <div class="card"><h3>🖨️ Print</h3><p>@media print — hides nav and UI elements when you print this page.</p></div>
      </div>
    </div>
    <div class="bp"></div>
  </body>
</html>
