Phase 1 of 2
Cursor, caret and resize
📖 Concept

cursor:pointer/grab/not-allowed/crosshair/wait. caret-color:#0284c7 styles the blinking cursor in inputs. resize:vertical on textareas. ::selection styles highlighted text.

style.css
.clickable { cursor: pointer; }
.draggable { cursor: grab; }
.blocked   { cursor: not-allowed; }
input  { caret-color: #0284c7; }
::selection { background: #bae6fd; color: #0f172a; }
textarea { resize: vertical; }
✏️ Your Task

Set caret-color blue on all inputs. Add selection styling. Restrict textarea resize to vertical only.

Phase 2 of 2
accent-color and scroll
📖 Concept

accent-color:#0284c7 brands checkboxes, radios and range inputs. scroll-behavior:smooth animates anchor scrolling. overscroll-behavior:contain prevents scroll chaining.

style.css
:root { accent-color: #0284c7; }
html  { scroll-behavior: smooth; scroll-padding-top: 70px; }
.modal { overscroll-behavior: contain; }
::-webkit-scrollbar       { width: 8px; }
::-webkit-scrollbar-thumb { background: #bae6fd; border-radius: 4px; }
::-webkit-scrollbar-thumb:hover { background: #0284c7; }
✏️ Your Task

Add :root{accent-color:#0284c7} — all native checkboxes, radios and ranges turn blue instantly. No extra CSS needed!
