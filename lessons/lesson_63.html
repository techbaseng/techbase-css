📚 2 phases 🏗️ Build: My Shadow Design System
Phase 1 of 2
Shadow syntax
📖 Concept

box-shadow: x y blur spread colour. inset = inner shadow. Multiple: comma-separated. Spread expands/shrinks. Hard shadow: no blur + offset. Glow: no x/y, just blur.

style.css
.shadow  { box-shadow: 4px 4px 12px rgba(0,0,0,.1); }
.glow    { box-shadow: 0 0 20px rgba(2,132,199,.4); }
.inset   { box-shadow: inset 0 2px 6px rgba(0,0,0,.15); }
.retro   { box-shadow: 5px 5px 0 0 #0f172a; }
.layered { box-shadow: 0 1px 2px rgba(0,0,0,.04), 0 4px 8px rgba(0,0,0,.07), 0 16px 32px rgba(0,0,0,.07); }
✏️ Your Task

Create 5 cards with different shadows: subtle, glow, inset, retro hard, layered. Add hover that raises the elevation.

Phase 2 of 2
Elevation system and coloured shadows
📖 Concept

Define shadow levels as CSS variables. Coloured shadows match the background for vivid modern depth. On hover, advance one level + translate up.

style.css
:root { --sh-xs:0 1px 2px rgba(0,0,0,.05); --sh-sm:0 2px 6px rgba(0,0,0,.08); --sh-md:0 4px 12px rgba(0,0,0,.1); --sh-lg:0 8px 24px rgba(0,0,0,.12); }
.el-1 { box-shadow: var(--sh-xs); } .el-1:hover { box-shadow: var(--sh-md); transform: translateY(-3px); }
.vivid-blue { box-shadow: 0 8px 20px rgba(2,132,199,.5); }
✏️ Your Task

Build 4 elevation cards with CSS variable shadows. On hover each card jumps one level. Add coloured shadow cards.
