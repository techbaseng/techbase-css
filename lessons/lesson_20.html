CSS Display

Control how elements appear and participate in layout using the display property. Work through 2 phases — complete each task before clicking Next Phase.

Phase 1
Block, Inline and Inline-Block
💡 Concept

block — full width, new line (div, p, h1). inline — fits in text, can't have width/height (span, a). inline-block — sits inline BUT accepts width, height and padding. This is how nav links and buttons work. Key trick: li { display: inline-block; } creates a horizontal navigation bar.

style.css 
/* Block — full width */
.block { display: block; }

/* Inline — flows with text */
.inline { display: inline; }

/* Inline-block — inline flow with block sizing */
.iblock { display: inline-block; width: 120px; height: 60px; padding: 10px; }

/* Making a link into a block button */
a.btn { display: inline-block; padding: 10px 20px; }

/* Horizontal nav from a list */
.nav li { display: inline-block; margin-right: 12px; }

/* Hiding elements */
.hidden   { display: none; }          /* removes completely */
.invisible{ visibility: hidden; }     /* hidden but space remains */

Phase 2
Flex, Grid and Hiding
💡 Concept

display: flex — children line up in a row. display: grid — children arranged in rows and columns. Full lessons on both coming up. display: none removes the element from the page entirely. visibility: hidden hides it but keeps the space. Common JS pattern: toggle a class that sets display: none to show/hide content.

style.css 
/* Flex — row layout */
.flex-row { display: flex; gap: 16px; align-items: center; }

/* Grid — 3 equal columns */
.grid-3 { display: grid; grid-template-columns: 1fr 1fr 1fr; gap: 16px; }

/* Visibility comparison */
.d-none       { display: none; }       /* gone, no space */
.invisible    { visibility: hidden; }   /* hidden, space kept */
.transparent  { opacity: 0; }          /* invisible, space kept, clickable */

/* Toggle pattern with JS */
.collapsed { display: none; }
/* JS: el.classList.toggle('collapsed') */
✏️ Your Task

Create a div with display: flex; gap: 16px; and put three coloured boxes inside. They should line up in a row. Then change to display: grid; grid-template-columns: 1fr 1fr 1fr; — same result, different method. Compare them!

My Display Demo Page

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Display Demo</title>
    <style>
      *, *::before, *::after { box-sizing: border-box; }
      body { font-family: Arial, sans-serif; background: #f0f9ff;
             padding: 30px; max-width: 860px; margin: 0 auto; color: #0f172a; }
      h1 { color: #0284c7; margin-bottom: 6px; }
      h2 { color: #0369a1; margin: 28px 0 14px; border-bottom: 2px solid #bae6fd; padding-bottom: 6px; }
      .demo { background: white; border: 1.5px solid #bae6fd; border-radius: 10px; padding: 16px 18px; margin-bottom: 12px; }
      .bl { display: block; background: #dbeafe; border-radius: 6px; padding: 10px; margin: 5px 0; color: #1e40af; font-size: 13px; }
      .inl { display: inline; background: #bbf7d0; padding: 2px 8px; border-radius: 4px; color: #166534; }
      .ibl { display: inline-block; width: 110px; height: 65px; background: #fef3c7; border-radius: 6px; padding: 10px; vertical-align: top; font-size: 11px; color: #78350f; text-align: center; line-height: 1.4; margin: 2px; }
      .nav-ul { list-style: none; padding: 0; margin: 0; background: #0284c7; border-radius: 10px; padding: 8px 16px; }
      .nav-ul li { display: inline-block; }
      .nav-ul li a { color: white; text-decoration: none; font-weight: 700; font-size: 14px; padding: 8px 14px; border-radius: 7px; display: inline-block; transition: background .15s; }
      .nav-ul li a:hover { background: rgba(255,255,255,.2); }
      .flex-row { display: flex; gap: 14px; }
      .flex-row div { flex: 1; background: #dbeafe; border-radius: 8px; padding: 16px; font-size: 13px; color: #1e40af; }
      .grid3 { display: grid; grid-template-columns: 1fr 1fr 1fr; gap: 14px; }
      .grid3 div { background: #dcfce7; border-radius: 8px; padding: 16px; font-size: 13px; color: #166534; }
    </style>
  </head>
  <body>
    <h1>CSS Display Property</h1>

    <h2>display: block</h2>
    <div class="demo">
      <div class="bl">Block 1 — full width, new line</div>
      <div class="bl">Block 2 — always on its own line</div>
    </div>

    <h2>display: inline</h2>
    <div class="demo"><p style="font-size:15px">Text with <span class="inl">inline span</span> and <span class="inl">another</span> flowing naturally in the text.</p></div>

    <h2>display: inline-block</h2>
    <div class="demo">
      <div class="ibl">inline-block 1</div>
      <div class="ibl">inline-block 2</div>
      <div class="ibl">inline-block 3</div>
    </div>

    <h2>Inline-block Nav</h2>
    <ul class="nav-ul">
      <li><a href="#">Home</a></li>
      <li><a href="#">Courses</a></li>
      <li><a href="#">About</a></li>
      <li><a href="#">Contact</a></li>
    </ul>

    <h2>display: flex</h2>
    <div class="demo"><div class="flex-row"><div>Child 1</div><div>Child 2</div><div>Child 3</div></div></div>

    <h2>display: grid (3 columns)</h2>
    <div class="demo"><div class="grid3"><div>1</div><div>2</div><div>3</div><div>4</div><div>5</div><div>6</div></div></div>
  </body>
</html>
