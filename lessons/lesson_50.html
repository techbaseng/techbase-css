Phase 1
Flexbox + Media Queries
💡 Concept

The power of responsive design: Flexbox handles the distribution of space, media queries change the direction and wrapping at different screen widths. Mobile-first: flex-direction: column by default, then flex-direction: row at tablet+. Card grid: flex: 1 1 100% on mobile, flex: 1 1 calc(50% - 8px) on tablet, flex: 1 1 calc(33.33% - 11px) on desktop.

style.css 
/* Mobile-first card grid */
.cards { display: flex; flex-wrap: wrap; gap: 16px; }
.card  { flex: 1 1 100%; }  /* full width on mobile */

@media (min-width: 600px) {
  .card { flex: 1 1 calc(50% - 8px); }  /* 2 columns */
}
@media (min-width: 960px) {
  .card { flex: 1 1 calc(33.33% - 11px); } /* 3 columns */
}

/* Sidebar layout — stacked on mobile, side by side on desktop */
.page { display: flex; flex-direction: column; gap: 24px; }
.main    { flex: 1; }
.sidebar { width: 100%; }

@media (min-width: 768px) {
  .page { flex-direction: row; }
  .sidebar { width: 260px; flex-shrink: 0; }
}
✏️ Your Task

Build a responsive card grid: one column on mobile, two on tablet (600px+), three on desktop (960px+). Use flex: 1 1 calc(N% - gap) for each breakpoint. Test at all three widths using browser DevTools.

Phase 2
Complete Responsive Component Patterns
💡 Concept

Putting it all together: responsive navbar (hamburger on mobile, horizontal links on tablet), responsive sidebar (stacked below on mobile, side by side on desktop), responsive footer (stacked on mobile, horizontal on desktop). These are the three core patterns used in almost every professional website.

style.css 
/* Responsive navbar */
.navbar { display: flex; align-items: center; padding: 0 20px; flex-wrap: wrap; gap: 8px; }
.nav-links { display: none; width: 100%; flex-direction: column; }
.nav-links.open { display: flex; }
@media (min-width: 768px) {
  .nav-links { display: flex; flex-direction: row; width: auto; }
  .hamburger { display: none; }
}

/* Responsive sidebar */
.page { display: flex; flex-direction: column; gap: 24px; padding: 24px; }
@media (min-width: 768px) { .page { flex-direction: row; } }

/* Responsive footer */
footer { display: flex; flex-direction: column; gap: 16px; align-items: center; }
@media (min-width: 640px) { footer { flex-direction: row; justify-content: space-between; } }
✏️ Your Task

Combine everything into a complete page: responsive navbar + responsive card grid + responsive sidebar layout. Test on phone, tablet, and desktop sizes. Each section should adapt independently.

Try the task first, then click to continue!
