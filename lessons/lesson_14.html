Phase 1
Colour, Alignment and Decoration
💡 Concept

Text colour uses color. text-align: left (default), right, center, justify. text-decoration: none (removes link underlines), underline, line-through — style it too: underline wavy #ea4f21. text-transform: uppercase, lowercase, capitalize (first letter of each word).

style.css 
/* Alignment */
.left    { text-align: left; }
.centre  { text-align: center; }
.right   { text-align: right; }
.justify { text-align: justify; }

/* Decoration */
a         { text-decoration: none; }
.strike   { text-decoration: line-through; }
.wavy     { text-decoration: underline wavy #ea4f21; }

/* Transform */
.upper    { text-transform: uppercase; letter-spacing: .1em; }
.capital  { text-transform: capitalize; }
✏️ Your Task

Take a paragraph and try all four text-align values. Apply text-transform: uppercase to a heading — type it in normal case but display it in caps. Add text-decoration: underline wavy #ea4f21 to a word.

Phase 2
Spacing, Shadow and Special Effects
💡 Concept

line-height: 1.5–1.8 is best for body text. letter-spacing adds space between characters. text-shadow: x y blur colour adds a shadow. Multiple shadows: comma-separated. Gradient text: background: linear-gradient(...); -webkit-background-clip: text; -webkit-text-fill-color: transparent;

style.css 
/* Spacing */
.body-text  { line-height: 1.8; }
.tight-head { line-height: 1.15; letter-spacing: -.02em; }
.spaced-tag { letter-spacing: .12em; text-transform: uppercase; }

/* Text shadow */
.shadow-soft { text-shadow: 2px 2px 6px rgba(0,0,0,.15); }
.shadow-3d   { text-shadow: 2px 2px 0 #0369a1, 4px 4px 0 #bae6fd; }
.glow { color: white;
  text-shadow: 0 0 16px rgba(2,132,199,.9), 0 0 32px rgba(2,132,199,.5); }

/* Gradient text */
.grad-text {
  background: linear-gradient(to right, #0284c7, #7c3aed);
  -webkit-background-clip: text;
  -webkit-text-fill-color: transparent;
}
✏️ Your Task

Add a soft shadow to your h1. Create a glowing text effect: white text on a dark background with text-shadow: 0 0 20px rgba(2,132,199,.8). Then try the gradient text technique.

Try the task first, then click to continue!

My Typography Showcase

Build a typography showcase demonstrating alignment, decoration, shadow, and gradient text.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Typography</title>
    <style>
      *, *::before, *::after { box-sizing: border-box; }
      body { font-family: Arial, sans-serif; background: #f0f9ff;
             padding: 30px; max-width: 820px; margin: 0 auto; color: #0f172a; }
      h1 { color: #0284c7; margin-bottom: 6px; }
      h2 { color: #0369a1; margin: 28px 0 14px;
           border-bottom: 2px solid #bae6fd; padding-bottom: 6px; }
      .demo { background: white; border: 1.5px solid #bae6fd;
              border-radius: 10px; padding: 14px 18px; margin-bottom: 10px; }
      .grad-head {
        font-size: 2.2rem; font-weight: 800;
        background: linear-gradient(to right, #0284c7, #7c3aed, #ea4f21);
        -webkit-background-clip: text; -webkit-text-fill-color: transparent;
        margin-bottom: 20px;
      }
      .glow-box { background: #0f172a; border-radius: 12px; padding: 24px; margin-bottom: 10px; }
      .glow-text { font-size: 1.8rem; font-weight: bold; color: white;
                   text-shadow: 0 0 16px rgba(2,132,199,.9), 0 0 32px rgba(2,132,199,.5); }
    </style>
  </head>
  <body>
    <h1>CSS Typography Showcase</h1>
    <p class="grad-head">Gradient Text Effect</p>

    <h2>Text Alignment</h2>
    <div class="demo" style="text-align:left">text-align: left — the default</div>
    <div class="demo" style="text-align:center;color:#0284c7">text-align: center</div>
    <div class="demo" style="text-align:right;color:#0369a1">text-align: right</div>
    <div class="demo" style="text-align:justify;color:#334155">text-align: justify — spreads words to fill the full width of the line, just like a printed newspaper or book column would appear.</div>

    <h2>Text Decoration</h2>
    <div class="demo">
      <a style="text-decoration:none;color:#0284c7;font-weight:600">No underline</a>&nbsp; |&nbsp;
      <span style="text-decoration:underline">underline</span>&nbsp; |&nbsp;
      <span style="text-decoration:line-through">strikethrough</span>&nbsp; |&nbsp;
      <span style="text-decoration:underline wavy #ea4f21">wavy orange</span>
    </div>

    <h2>Text Transform</h2>
    <div class="demo">
      <p style="text-transform:uppercase;letter-spacing:.1em;color:#0284c7;font-weight:700">uppercase with letter-spacing</p>
      <p style="text-transform:capitalize;color:#334155">capitalize — every First Letter</p>
    </div>

    <h2>Text Shadow</h2>
    <div class="demo">
      <p style="font-size:1.5rem;font-weight:bold;text-shadow:2px 2px 6px rgba(0,0,0,.15)">Soft shadow</p>
      <p style="font-size:1.5rem;font-weight:bold;color:#0284c7;text-shadow:2px 2px 0 #0369a1,4px 4px 0 #bae6fd">3D stacked shadow</p>
    </div>
    <div class="glow-box"><p class="glow-text">Glowing text 🌟</p></div>
  </body>
</html>
