Phase 1
The Four Link States — LVHA
💡 Concept

Links have four pseudo-class states written in LVHA order: :link (never clicked), :visited (already clicked), :hover (mouse over), :active (being clicked). They must be in this order — LoVe HAte — because they can override each other. By default links are blue, purple when visited, and red when active.

style.css 
/* LVHA — must be in this order! */
a:link    { color: #0284c7; text-decoration: underline; }
a:visited { color: #7c3aed; }
a:hover   { color: #0369a1; text-decoration: none; }
a:active  { color: #ea4f21; }

/* Common pattern: no underline by default, add on hover */
a { text-decoration: none; color: #0284c7; font-weight: 600; }
a:hover { text-decoration: underline; }

/* Contextual link selectors */
a[href^="https"]::after    { content: ' ↗'; font-size: .8em; }
a[href$=".pdf"]::after     { content: ' 📄'; }
a[target="_blank"]::after  { content: ' ↗'; opacity: .7; font-size: .8em; }
✏️ Your Task

Style your links in LVHA order. Add a ↗ after all links that open in a new tab using a[target='_blank']::after { content: ' ↗'; }. Test: visit a link, come back — it should be purple.

Phase 2
Button-Style Links and Animated Underlines
💡 Concept

Links are just elements — style them to look like buttons using display: inline-block and padding. Animated underline technique: hide default underline, add a pseudo-element that animates width from 0 to 100% on hover. Use transition for smooth animation.

style.css 
/* Filled button */
.btn-filled {
  display: inline-block;
  background: #0284c7; color: white;
  padding: 11px 24px; border-radius: 9px;
  text-decoration: none; font-weight: 700;
  transition: background .2s, transform .15s;
}
.btn-filled:hover { background: #0369a1; transform: translateY(-2px); }

/* Outline button */
.btn-outline {
  display: inline-block;
  border: 2px solid #0284c7; color: #0284c7;
  padding: 9px 22px; border-radius: 9px;
  text-decoration: none; font-weight: 700;
  transition: background .2s, color .2s;
}
.btn-outline:hover { background: #0284c7; color: white; }

/* Animated underline */
.ul-link {
  position: relative; text-decoration: none; color: #0284c7;
}
.ul-link::after {
  content: ''; position: absolute;
  width: 0; height: 2px; background: #0284c7;
  bottom: -2px; left: 0; transition: width .3s ease;
}
.ul-link:hover::after { width: 100%; }
✏️ Your Task

Create all three: filled button, outline button, and animated underline. Hover over each. Then combine a filled button with an icon: <a class='btn-filled'><i class='bi bi-download'></i> Download</a>

Try the task first, then click to continue!
