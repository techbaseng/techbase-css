Phase 1
content-box vs border-box
💡 Concept

The default box-sizing: content-box means width = content area only. Adding padding or border increases the total rendered size. box-sizing: border-box includes padding and border inside the width — total rendered size = exactly the width you set. Always apply border-box globally: *, *::before, *::after { box-sizing: border-box; }

style.css 
/* DEFAULT — content-box */
.content-box {
  box-sizing: content-box;  /* default */
  width: 300px;
  padding: 20px;
  border: 2px solid #0284c7;
  /* Total = 300 + 40 (padding) + 4 (border) = 344px! */
}

/* BETTER — border-box */
.border-box {
  box-sizing: border-box;
  width: 300px;
  padding: 20px;
  border: 2px solid #ea4f21;
  /* Total = exactly 300px */
}

/* GLOBAL RESET — apply to every project */
*, *::before, *::after {
  box-sizing: border-box;
}

/* Why it matters: form inputs */
input {
  width: 100%;       /* fills container */
  padding: 12px;     /* with content-box, this would overflow! */
  border: 1.5px solid #cbd5e1;
}

Phase 2
Practical Impact on Layouts
💡 Concept

Without border-box, percentage layouts break: three width: 33.33% columns with padding overflow their container. With border-box they fit perfectly. This is especially important for form inputs — width: 100%; padding: 12px; would overflow without border-box. The universal * reset is the first rule in almost every professional stylesheet.

style.css 
/* Without border-box — broken layout */
.broken-col {
  display: inline-block;
  width: 33.33%;
  padding: 20px; /* causes overflow! */
}

/* With border-box — perfect */
*, *::before, *::after { box-sizing: border-box; }
.fixed-col {
  display: inline-block;
  width: 33.33%;
  padding: 20px; /* stays inside 33.33% */
}

/* Inheritance approach */
html { box-sizing: border-box; }
*, *::before, *::after { box-sizing: inherit; }
/* Allows components to opt-out if needed */

/* Check which model a browser uses */
/* Open DevTools → Computed tab → box-sizing */
✏️ Your Task

Create a three-column layout using display: inline-block; width: 33.33%;. First without the global border-box reset — add padding and see how it overflows. Then add *, *::before, *::after { box-sizing: border-box; } at the top — the columns snap into place.
