Phase 1
justify-content and align-items
💡 Concept

justify-content distributes space along the main axis: flex-start (default), flex-end, center, space-between (equal gaps between), space-around (equal space around each), space-evenly (equal space everywhere). align-items positions items on the cross axis: stretch (default — fills height), flex-start (top), flex-end (bottom), center, baseline.

style.css 
/* justify-content values */
.jc-start   { justify-content: flex-start; }   /* items at start */
.jc-end     { justify-content: flex-end; }     /* items at end */
.jc-center  { justify-content: center; }       /* items centred */
.jc-between { justify-content: space-between; }/* gaps between */
.jc-around  { justify-content: space-around; } /* gaps around */
.jc-evenly  { justify-content: space-evenly; } /* equal all gaps */

/* align-items values */
.ai-stretch { align-items: stretch; }   /* default — fill height */
.ai-start   { align-items: flex-start; }/* align to top */
.ai-end     { align-items: flex-end; }  /* align to bottom */
.ai-center  { align-items: center; }    /* centre vertically */
.ai-base    { align-items: baseline; }  /* align text baselines */
✏️ Your Task

Create a row of coloured boxes and try all 6 justify-content values. Notice the difference between space-between (first/last touch edges) and space-evenly (all gaps equal). Then try all 5 align-items values with boxes of different heights.

Phase 2
align-content, flex-flow and gap
💡 Concept

align-content works like justify-content but for multiple rows — only has effect when flex-wrap: wrap creates multiple lines. flex-flow is shorthand for flex-direction + flex-wrap: flex-flow: row wrap. gap (or row-gap + column-gap) sets consistent spacing between items — much cleaner than using margins.

style.css 
/* align-content — for multi-line flex containers */
.multi-line {
  display: flex;
  flex-wrap: wrap;
  height: 300px;       /* must have fixed height! */
  align-content: space-between; /* distribute rows */
}

/* flex-flow shorthand */
.row-wrap    { flex-flow: row wrap; }
.col-nowrap  { flex-flow: column nowrap; }

/* gap — cleaner than margin hacks */
.card-grid {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;            /* same gap in all directions */
}
.card-grid-diff {
  row-gap: 24px;
  column-gap: 12px;     /* different vertical and horizontal */
}
✏️ Your Task

Create a flex container with flex-wrap: wrap, a fixed height, and enough items to create two rows. Try all align-content values — notice how they distribute the rows within the container height. Use gap instead of margins for spacing.

Try the task first, then click to continue!
