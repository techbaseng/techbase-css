Phase 1
List Style Properties
💡 Concept

list-style-type: unordered options: disc, circle, square, none. Ordered options: decimal, lower-alpha, upper-roman. list-style-position: inside moves the bullet inside the text block. list-style: none; padding: 0; resets a list completely — required when building navigation menus from lists.

style.css 
/* Unordered types */
.disc   { list-style-type: disc; }
.circle { list-style-type: circle; }
.square { list-style-type: square; }
.none   { list-style-type: none; padding: 0; }

/* Ordered types */
.decimal { list-style-type: decimal; }
.alpha   { list-style-type: lower-alpha; }
.roman   { list-style-type: upper-roman; }

/* Nav list reset */
.nav-list { list-style: none; padding: 0; margin: 0; }
.nav-list a { display: block; padding: 10px 16px;
              color: #334155; text-decoration: none; }
.nav-list a:hover { background: #f0f9ff; color: #0284c7; }

Phase 2
Custom Bullets with ::before and Counters
💡 Concept

The best custom bullets use li::before. Remove the default with list-style: none, then inject any character or shape via content. CSS counters (counter-reset + counter-increment) let you create numbered badges with full styling control.

style.css 
/* Emoji bullet */
.emoji-list { list-style: none; padding: 0; }
.emoji-list li::before { content: '🔷 '; }

/* CSS dot bullet */
.dot-list { list-style: none; padding: 0; }
.dot-list li { padding: 8px 0 8px 24px; position: relative; }
.dot-list li::before {
  content: ''; position: absolute; left: 0; top: 50%;
  transform: translateY(-50%);
  width: 8px; height: 8px;
  background: #0284c7; border-radius: 50%;
}

/* Numbered badge list */
.num-list { list-style: none; padding: 0; counter-reset: num; }
.num-list li { padding: 12px 0 12px 46px; position: relative;
               border-bottom: 1px solid #e2e8f0; }
.num-list li::before {
  counter-increment: num; content: counter(num);
  position: absolute; left: 0; top: 50%; transform: translateY(-50%);
  width: 30px; height: 30px; background: #0284c7; color: white;
  border-radius: 50%; display: flex; align-items: center;
  justify-content: center; font-size: 13px; font-weight: bold;
}
✏️ Your Task
