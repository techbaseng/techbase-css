Phase 1
Content, Padding, Border and Margin
💡 Concept

Every HTML element is a box made of four layers from inside out: Content (text/images), Padding (space between content and border), Border (the visible outline), and Margin (space outside the border). This is the single most important CSS concept. Open DevTools → inspect any element → the Computed panel shows a box model diagram with all four layers and their values.

style.css 
/* The four layers demonstrated */
.box-demo {
  width: 200px;
  height: 100px;
  padding: 20px;           /* inside the border */
  border: 4px solid #0284c7;
  margin: 30px;            /* outside the border */
  background: #dbeafe;     /* fills content + padding */
}
/* With content-box (default):
   Total width = 200 + 40 (padding) + 8 (border) = 248px */

.border-box {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 4px solid #ea4f21;
  /* Total = exactly 200px */
}

Phase 2
box-sizing: border-box — The Game Changer
💡 Concept

By default width sets only the content area. Adding padding or border makes the element wider. box-sizing: border-box includes padding and border inside the width — far more predictable! Set it globally on every project: *, *::before, *::after { box-sizing: border-box; }. With border-box, width: 300px; padding: 20px; stays exactly 300px total.

style.css 
/* THE universal reset */
*, *::before, *::after { box-sizing: border-box; }

/* Three equal columns — add up to exactly 100% */
.col {
  float: left;
  width: 33.33%;
  padding: 20px;
  /* Without border-box, the padding would overflow! */
}

/* Predictable form inputs */
input {
  width: 100%;
  padding: 12px;
  border: 1.5px solid #cbd5e1;
  border-radius: 8px;
  /* Fills container without overflowing */
}
✏️ Your Task

Add *, *::before, *::after { box-sizing: border-box; } to the top of your stylesheet. Create three divs with width: 33.33%, display: inline-block, and generous padding. They should sit in a row without overflowing.

My Box Model Visualiser

Build a visual box model diagram and a three-column layout proving border-box works.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Box Model</title>
    <style>
      *, *::before, *::after { box-sizing: border-box; }
      body { font-family: Arial, sans-serif; background: #f0f9ff;
             padding: 30px; max-width: 900px; margin: 0 auto; color: #0f172a; }
      h1 { color: #0284c7; margin-bottom: 6px; }
      h2 { color: #0369a1; margin: 32px 0 16px; }
      .bm-margin  { background: #fde68a; padding: 24px; border-radius: 8px;
                    font-size: 12px; color: #78350f; font-weight: bold; }
      .bm-border  { background: #0284c7; padding: 16px; border-radius: 4px; }
      .bm-padding { background: #bbf7d0; padding: 20px; border-radius: 2px;
                    font-size: 12px; color: #166534; font-weight: bold; }
      .bm-content { background: #dbeafe; padding: 24px; text-align: center;
                    font-size: 13px; color: #1e40af; font-weight: bold; }
      .cols { display: flex; gap: 16px; }
      .col  { flex: 1; padding: 24px; background: white; border: 1.5px solid #bae6fd;
              border-radius: 12px; border-top: 4px solid #0284c7; }
      .col h3 { color: #0284c7; margin: 0 0 8px; }
      .col p  { color: #475569; font-size: 14px; margin: 0; }
    </style>
  </head>
  <body>
    <h1>The CSS Box Model</h1>
    <h2>Box Model Layers</h2>
    <div class="bm-margin">
      🟡 MARGIN — outside the border
      <div class="bm-border" style="margin-top:8px;">
        <div style="color:white;font-size:12px;margin-bottom:8px;">🔵 BORDER</div>
        <div class="bm-padding">
          🟢 PADDING — inside the border
          <div class="bm-content" style="margin-top:8px;">📄 CONTENT</div>
        </div>
      </div>
    </div>
    <h2>Three Equal Columns (border-box)</h2>
    <div class="cols">
      <div class="col"><h3>Column 1</h3><p>flex: 1 with generous padding — still fits perfectly.</p></div>
      <div class="col"><h3>Column 2</h3><p>All three share space equally. border-box makes this reliable.</p></div>
      <div class="col"><h3>Column 3</h3><p>Without border-box, adding padding would break this layout!</p></div>
    </div>
  </body>
</html>
