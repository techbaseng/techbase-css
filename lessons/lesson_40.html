Phase 1
The Specificity Hierarchy
💡 Concept

When multiple CSS rules target the same element, specificity determines the winner. The hierarchy (highest to lowest): (1) !important. (2) Inline styles. (3) ID selectors (#id) — 1-0-0. (4) Class, attribute, pseudo-class selectors (.class, [attr], :hover) — 0-1-0. (5) Element and pseudo-element selectors (div, p, ::before) — 0-0-1. Specificity is counted as three numbers (IDs, Classes, Elements). Higher wins.

style.css 
/* Specificity values (IDs, Classes, Elements) */

p { color: gray; }          /* 0-0-1 */
.text { color: blue; }      /* 0-1-0 — wins over p */
#content { color: green; }  /* 1-0-0 — wins over .text */

/* Combining selectors increases specificity */
div p { color: red; }         /* 0-0-2 */
div.card p { color: orange; } /* 0-1-2 — wins over div p */

/* Pseudo-classes count as classes */
a:hover { color: blue; } /* 0-1-1 */

/* Pseudo-elements count as elements */
p::first-line { color: blue; } /* 0-0-2 */

/* When specificity ties, LAST rule wins */
p { color: red; }
p { color: blue; } /* Blue wins — same specificity, later rule */

Phase 2
Calculating and Managing Specificity
💡 Concept

Calculate specificity by counting: IDs = hundreds, Classes/Attributes/Pseudo-classes = tens, Elements/Pseudo-elements = ones. div.card:hover p.text = 0 IDs + 3 classes + 2 elements = 032. The universal selector *, combinators (+, >, ~), and :is(), :not() (but not their arguments) have zero specificity. Best practice: keep specificity LOW — avoid IDs in CSS, avoid inline styles, avoid !important.

style.css 
/* Low specificity — easy to override */
.btn { color: white; background: gray; }  /* 0-1-0 */
.btn-primary { background: #0284c7; }     /* 0-1-0 — same, latter wins */
.btn-danger  { background: #ef4444; }     /* 0-1-0 */

/* High specificity — hard to override (avoid!) */
nav ul li a.btn { background: #0284c7; }  /* 0-1-4 — overkill! */

/* :is() matches with the highest specificity of its arguments */
:is(#header, .nav) a { color: white; }  /* takes #header's 1-0-1 */

/* :where() — zero specificity (great for reset styles) */
:where(h1, h2, h3) { margin-top: 0; }  /* 0-0-0 — easily overridden */

/* Layer system (modern CSS) */
@layer base { p { color: gray; } }    /* lower priority */
@layer theme { p { color: blue; } }   /* higher priority */
