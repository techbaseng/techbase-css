Phase 1
Flex Container Basics
💡 Concept

display: flex makes a container a flex container — its direct children become flex items. Default behaviour: children line up in a row (flex-direction: row), don't wrap (flex-wrap: nowrap), and stretch to fill the container height. Change direction with flex-direction: column. Wrap overflowing items with flex-wrap: wrap.

style.css 
/* Basic flex container */
.container {
  display: flex;             /* enable flexbox */
  flex-direction: row;       /* row (default) or column */
  flex-wrap: wrap;           /* allow wrapping */
  gap: 16px;                 /* space between items */
}

/* Flex direction */
.row    { flex-direction: row; }         /* left → right */
.col    { flex-direction: column; }      /* top → bottom */
.row-r  { flex-direction: row-reverse; }
.col-r  { flex-direction: column-reverse; }

/* Shorthand: flex-flow = direction + wrap */
.card-row { flex-flow: row wrap; gap: 16px; }

Phase 2
Alignment — justify-content and align-items
💡 Concept

justify-content aligns items along the main axis (the direction of flex-direction): flex-start, flex-end, center, space-between, space-around, space-evenly. align-items aligns along the cross axis: stretch (default), flex-start, flex-end, center, baseline. To centre both axes: justify-content: center; align-items: center;

style.css 
/* Alignment */
.space-between { justify-content: space-between; }
.centre-h      { justify-content: center; }
.centre-both   { justify-content: center; align-items: center; }

/* Common patterns */
.navbar {
  display: flex;
  align-items: center;        /* vertically centre all items */
  justify-content: space-between; /* logo left, links right */
}

.hero {
  display: flex;
  flex-direction: column;
  justify-content: center;
  align-items: center;
  text-align: center;
  min-height: 100vh;
}

/* Align individual item differently */
.ml-auto { margin-left: auto; } /* push this item to the far right */
