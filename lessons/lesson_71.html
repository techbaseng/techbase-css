Reveal elements through gradient masks using mask-image

📚 2 phases 🏗️ Build: My CSS Masking Effects
Phase 1 of 2
mask-image and gradients
📖 Concept

mask-image uses a gradient or image as a transparency mask: black = visible, transparent = hidden. Fade bottom: mask-image: linear-gradient(to bottom, black 60%, transparent). Always add -webkit- prefix for Safari.

style.css
.fade-bottom {
  mask-image: linear-gradient(to bottom, black 60%, transparent);
  -webkit-mask-image: linear-gradient(to bottom, black 60%, transparent);
}
.vignette {
  mask-image: radial-gradient(ellipse at center, black 50%, transparent 100%);
  -webkit-mask-image: radial-gradient(ellipse at center, black 50%, transparent 100%);
}
✏️ Your Task

Apply a bottom-fade mask to a long text block. The text fades out at the bottom — great for collapsed content with a 'Read more' link.

Phase 2 of 2
Animated mask shimmer
📖 Concept

Animate mask-position to create a light-sweep effect. Useful for 'loading' text or hero highlights.

style.css
@keyframes mask-slide { from{mask-position:-100% 0} to{mask-position:200% 0} }
.shimmer-text {
  mask-image: linear-gradient(90deg, transparent 20%, black 50%, transparent 80%);
  -webkit-mask-image: linear-gradient(90deg, transparent 20%, black 50%, transparent 80%);
  mask-size: 200% 100%;
  -webkit-mask-size: 200% 100%;
  animation: mask-slide 2s linear infinite;
}
✏️ Your Task

Create a shimmer mask text: gradient mask that sweeps across the element. Used for 'NEW', 'LOADING', or hero badge highlights.
