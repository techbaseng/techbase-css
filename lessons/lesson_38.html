CSS Website Layout

Phase 1
Header, Main and Footer Layout
💡 Concept

A standard website layout: fixed <header> at top, <main> in the middle (taking remaining height with min-height: 100vh), sticky or fixed <footer> at the bottom. For multi-column layouts inside main: use Flexbox (for 1D rows/columns) or Grid (for 2D). The sidebar+content pattern uses display: flex; gap: 24px;.

style.css 
/* Full-page layout */
body {
  display: flex;
  flex-direction: column;
  min-height: 100vh;
}

header { position: sticky; top: 0; z-index: 100; }
main   { flex: 1; }    /* grows to fill remaining space */
footer { margin-top: auto; }

/* Three-section inner layout */
.page-body {
  display: flex;
  gap: 28px;
  max-width: 1100px;
  margin: 0 auto;
  padding: 32px 24px;
}

.sidebar  { width: 240px; flex-shrink: 0; }
.content  { flex: 1; min-width: 0; } /* min-width prevents overflow */
.right-col { width: 200px; flex-shrink: 0; }
✏️ Your Task

Build a page with a sticky header, a three-column layout (sidebar + main content + aside), and a footer. The main content area should grow to fill available space. Use min-width: 0 on flex children to prevent overflow with long content.

Try the task first, then click to continue!

Phase 2
Section Patterns and Full-bleed
💡 Concept

Common section patterns: full-bleed (background goes edge to edge), boxed (content constrained by max-width inside a full-width section). Hero sections often use min-height: 100vh; display: flex; align-items: center;. Alternating section backgrounds create visual rhythm. A card grid inside a section uses display: grid; grid-template-columns: repeat(auto-fill, minmax(260px, 1fr));

style.css 
/* Full-bleed with centred content */
.section { padding: 72px 24px; }
.section .inner { max-width: 1000px; margin: 0 auto; }

/* Alternating backgrounds */
.section:nth-child(even) { background: #f0f9ff; }
.section:nth-child(odd)  { background: white; }

/* Hero */
.hero {
  min-height: 100vh;
  display: flex; align-items: center;
  background: linear-gradient(135deg, #0f172a, #0369a1);
  padding: 60px 24px;
}

/* Feature card grid */
.feature-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(260px, 1fr));
  gap: 24px;
}
✏️ Your Task

Add three full-bleed sections to your page: a hero, a features section, and a call-to-action. Alternate background colours between sections. The hero should be full-viewport height with centred content. The features section should have a responsive card grid.

Try the task first, then click to continue!
