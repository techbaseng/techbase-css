CSS Counters

Create automatic numbering systems for lists, headings and sections using CSS counters. Work through 2 phases — complete each task before clicking Next Phase.

Phase 1
counter-reset and counter-increment
💡 Concept

CSS counters automatically number elements. Three steps: (1) counter-reset: my-counter on a parent — initialises the counter at 0. (2) counter-increment: my-counter on each element — adds 1. (3) content: counter(my-counter) in a ::before pseudo-element — displays the count. Counters can be nested, reset at any level, and combined with text: content: 'Section ' counter(ch) '.'

style.css 
/* 1. Reset on parent */
.numbered-list { counter-reset: item; list-style: none; padding: 0; }

/* 2. Increment on each item */
.numbered-list li { counter-increment: item; padding: 12px 0 12px 48px;
                    position: relative; border-bottom: 1px solid #e2e8f0; }

/* 3. Display in ::before */
.numbered-list li::before {
  content: counter(item);
  position: absolute; left: 0; top: 50%; transform: translateY(-50%);
  width: 30px; height: 30px; background: #0284c7; color: white;
  border-radius: 50%; display: flex; align-items: center;
  justify-content: center; font-size: 13px; font-weight: bold;
}

/* With text */
.chapter { counter-increment: chapter; }
.chapter::before { content: 'Chapter ' counter(chapter) ': '; color: #0284c7; }

Phase 2
Nested Counters and Section Numbering
💡 Concept

Nest counters for hierarchical numbering (1, 1.1, 1.2, 2, 2.1…). Use counters(name, separator) (plural) to display nested counts with a separator. This is how legal documents, technical manuals and table-of-contents numbering works. Reset the inner counter on each parent to restart child numbering at 1.

style.css 
/* Nested counter (1, 1.1, 1.2, 2, 2.1...) */
.toc { counter-reset: section; }

.toc h2 {
  counter-reset: subsection;
  counter-increment: section;
}
.toc h2::before {
  content: counter(section) '. ';
  color: #0284c7;
}

.toc h3 { counter-increment: subsection; }
.toc h3::before {
  content: counter(section) '.' counter(subsection) ' ';
  color: #7c3aed;
}

/* Page counter (for print) */
@page { margin: 2cm; }
@page:right { @bottom-right { content: 'Page ' counter(page); } }

/* Step counter */
.steps { counter-reset: step; }
.step  { counter-increment: step; }
.step::before {
  content: 'Step ' counter(step);
  background: #0284c7; color: white;
  padding: 4px 12px; border-radius: 100px; font-size: 12px;
  font-weight: bold; margin-right: 10px;
}
