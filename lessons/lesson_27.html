CSS Align

Centre and align elements horizontally and vertically using multiple CSS techniques. Work through 2 phases — complete each task before clicking Next Phase.

Phase 1
Horizontal Centring
💡 Concept

Three ways to centre horizontally: (1) Block elements — margin: 0 auto with a defined width. (2) Inline/inline-block — text-align: center on the parent. (3) Flex — display: flex; justify-content: center;. Text inside a block is centred with text-align: center.

style.css 
/* Centre a block element */
.centred-block {
  width: 500px;
  margin: 0 auto;
}

/* Centre inline content */
.text-centre { text-align: center; }

/* Centre with flex */
.flex-centre {
  display: flex;
  justify-content: center;
}

/* Centre an image */
img.centred {
  display: block;
  margin: 0 auto;
}

/* Centre absolutely positioned */
.abs-h-centre {
  position: absolute;
  left: 50%;
  transform: translateX(-50%);
}

Phase 2
Vertical Centring
💡 Concept

Vertical centring is trickier. Four techniques: (1) Flexbox — display: flex; align-items: center; on the parent (best for most cases). (2) Grid — display: grid; place-items: center;. (3) Absolute + transform — position: absolute; top: 50%; transform: translateY(-50%);. (4) Line-height — set equal to height (only for single-line text).

style.css 
/* Flex — both axes */
.flex-center {
  display: flex;
  justify-content: center; /* horizontal */
  align-items: center;     /* vertical */
  height: 200px;
}

/* Grid — shorthand */
.grid-center {
  display: grid;
  place-items: center;
  height: 200px;
}

/* Absolute + transform */
.parent { position: relative; height: 200px; }
.abs-center {
  position: absolute;
  top: 50%;  left: 50%;
  transform: translate(-50%, -50%);
}

/* Line-height (single-line text only) */
.lh-center {
  height: 60px;
  line-height: 60px;
  text-align: center;
}

🏗️ Build It!
My Centred Layout Demo

Build a page showcasing all centring techniques — horizontal, vertical, and both axes.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Alignment</title>
    <style>
      *, *::before, *::after { box-sizing: border-box; }
      body { font-family: Arial, sans-serif; background: #f0f9ff;
             padding: 30px; max-width: 900px; margin: 0 auto; color: #0f172a; }
      h1 { color: #0284c7; margin-bottom: 6px; }
      h2 { color: #0369a1; margin: 28px 0 14px;
           border-bottom: 2px solid #bae6fd; padding-bottom: 6px; }
      .demo { background: #e0f2fe; border-radius: 12px; margin-bottom: 14px;
              border: 2px dashed #0284c7; height: 120px; }
      .box { background: #0284c7; color: white; font-weight: bold;
             padding: 14px 24px; border-radius: 10px; font-size: 14px; }
      /* Horizontal methods */
      .h1 { display: flex; justify-content: center; align-items: center; }
      .h2 { text-align: center; display: flex; align-items: center; justify-content: center; }
      .h3 .box { margin: 0 auto; display: block; width: fit-content; margin-top: 40px; }
      /* Full centre */
      .fc-flex { display: flex; justify-content: center; align-items: center; }
      .fc-grid { display: grid; place-items: center; }
      /* Absolute centre */
      .abs-parent { position: relative; }
      .abs-child  { position: absolute; top: 50%; left: 50%;
                    transform: translate(-50%, -50%); }
      /* Full viewport card */
      .vp-demo {
        background: linear-gradient(135deg, #0284c7, #0369a1);
        border-radius: 16px; height: 250px; margin-top: 16px;
        display: flex; align-items: center; justify-content: center;
      }
      .vp-card {
        background: white; border-radius: 14px; padding: 28px 36px;
        text-align: center; box-shadow: 0 8px 32px rgba(0,0,0,.15);
      }
      .vp-card h3 { color: #0284c7; margin: 0 0 6px; }
      .vp-card p  { color: #475569; font-size: 13px; margin: 0; }
    </style>
  </head>
  <body>
    <h1>CSS Alignment</h1>

    <h2>Horizontal — flex justify-content: center</h2>
    <div class="demo h1"><div class="box">Centred horizontally</div></div>

    <h2>Vertical + Horizontal — flex align-items + justify-content</h2>
    <div class="demo fc-flex"><div class="box">Both axes: flex</div></div>

    <h2>Vertical + Horizontal — grid place-items: center</h2>
    <div class="demo fc-grid"><div class="box">Both axes: grid</div></div>

    <h2>Absolute + transform: translate(-50%, -50%)</h2>
    <div class="demo abs-parent">
      <div class="abs-child box">Absolute centre</div>
    </div>

    <h2>Real-world: Centred Card on a Hero</h2>
    <div class="vp-demo">
      <div class="vp-card">
        <h3>🎯 Perfectly Centred</h3>
        <p>Flex + align-items + justify-content<br>— the modern standard</p>
      </div>
    </div>
  </body>
</html>
