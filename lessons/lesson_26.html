CSS Inline-block

Use inline-block to build horizontal layouts without Flexbox or Grid. Work through 2 phases — complete each task before clicking Next Phase.

Phase 1
Inline-block for Horizontal Layouts
💡 Concept

display: inline-block lets elements sit side by side (like inline) while accepting width, height, and padding (like block). You can build horizontal card rows, button groups, and icon grids without Flexbox. One gotcha: whitespace in your HTML creates tiny gaps between inline-block elements — fix with font-size: 0 on the parent, or use comments <!-- --> between elements.

style.css 
/* Basic inline-block row */
.card {
  display: inline-block;
  width: 200px;
  padding: 20px;
  background: white;
  border: 1.5px solid #e2e8f0;
  border-radius: 12px;
  vertical-align: top; /* align tops, not baselines */
}

/* Fix the whitespace gap */
.card-row { font-size: 0; }        /* parent gets 0 */
.card-row .card { font-size: 1rem; } /* restore in child */

/* Percentage widths */
.col-33 {
  display: inline-block;
  width: 33.33%;
  padding: 16px;
  vertical-align: top;
  box-sizing: border-box;
}

Phase 2
Inline-block vs Flexbox
💡 Concept

Inline-block works for simple horizontal layouts but has quirks: whitespace gaps, vertical alignment headaches, and no easy equal-height columns. Flexbox and Grid solve all these. Use inline-block today for: button groups, icon rows, navigation pills, or anywhere you need a quick inline layout without the full power of Flex/Grid (which come in lessons 48–50).

style.css 
/* Good inline-block uses */

/* Button group */
.btn-group .btn {
  display: inline-block;
  padding: 8px 16px;
  border: 1px solid #0284c7;
  color: #0284c7;
  cursor: pointer;
  margin: 0;
}
.btn-group .btn:first-child { border-radius: 8px 0 0 8px; }
.btn-group .btn:last-child  { border-radius: 0 8px 8px 0; }
.btn-group .btn.active { background: #0284c7; color: white; }

/* Tag/pill list */
.tag {
  display: inline-block;
  padding: 4px 12px;
  background: #dbeafe;
  color: #1e40af;
  border-radius: 100px;
  font-size: 12px;
  font-weight: 700;
  margin: 3px;
}
✏️ Your Task

My Inline-block Grid

Build a three-column card grid and a tag cloud using only inline-block.

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Inline-block</title>
    <style>
      *, *::before, *::after { box-sizing: border-box; }
      body { font-family: Arial, sans-serif; background: #f0f9ff;
             padding: 30px; max-width: 900px; margin: 0 auto; color: #0f172a; }
      h1 { color: #0284c7; margin-bottom: 6px; }
      h2 { color: #0369a1; margin: 28px 0 14px;
           border-bottom: 2px solid #bae6fd; padding-bottom: 6px; }
      /* Three-column card grid */
      .card-row { font-size: 0; margin: -8px; }
      .card {
        display: inline-block;
        width: 33.33%;
        padding: 8px;
        font-size: 1rem;
        vertical-align: top;
      }
      .card-inner {
        background: white; border: 1.5px solid #bae6fd;
        border-radius: 14px; padding: 22px;
        height: 100%;
      }
      .card-inner h3 { color: #0284c7; margin: 0 0 8px; font-size: 15px; }
      .card-inner p  { color: #475569; font-size: 13px; line-height: 1.7; margin: 0; }
      /* Button group */
      .btn-group { display: inline-flex; }
      .btn-group .btn {
        display: inline-block; padding: 10px 20px;
        border: 2px solid #0284c7; color: #0284c7;
        background: white; cursor: pointer; font-size: 14px;
        font-weight: 700; text-decoration: none;
        transition: background .15s, color .15s;
      }
      .btn-group .btn:first-child { border-radius: 9px 0 0 9px; }
      .btn-group .btn:last-child  { border-radius: 0 9px 9px 0; }
      .btn-group .btn:not(:first-child) { border-left: none; }
      .btn-group .btn:hover,
      .btn-group .btn.active { background: #0284c7; color: white; }
      /* Tags */
      .tags { margin-top: 12px; }
      .tag {
        display: inline-block; padding: 5px 14px;
        border-radius: 100px; font-size: 12px; font-weight: 700; margin: 4px;
      }
      @media (max-width: 640px) { .card { width: 100%; } }
    </style>
  </head>
