Phase 1
Float Basics
💡 Concept

float removes an element from normal flow and pushes it left or right, letting text wrap around it. Values: left, right, none. Today floats are mainly used for wrapping text around images — for layout, use Flexbox or Grid. Always add margin between the float and the text wrapping around it.

style.css 
/* Float image left — text wraps right */
.float-left {
  float: left;
  margin: 0 16px 12px 0;
  border-radius: 8px;
}

/* Float image right — text wraps left */
.float-right {
  float: right;
  margin: 0 0 12px 16px;
  border-radius: 8px;
}

/* Clear — stop content from wrapping next to float */
.clear       { clear: both; }
.clear-left  { clear: left; }
.clear-right { clear: right; }
✏️ Your Task

Add an image to a paragraph and set float: left. Add margin: 0 16px 12px 0. Text should wrap to the right. Try float: right — text wraps left. Notice how floated images are used in newspaper-style layouts.

Phase 2
Clearfix and Containing Floats
💡 Concept

A common problem: a parent div with only floated children collapses to zero height. The modern fix is display: flow-root on the parent — cleaner than the old clearfix hack. Another option: overflow: hidden on the parent. Always use one of these when floated children should be contained in their parent.

style.css 
/* Problem: parent collapses */
.broken { background: #dbeafe; /* invisible — height: 0 */ }
.broken img { float: left; }

/* Fix 1: display flow-root (best modern approach) */
.fix-flow { display: flow-root; }

/* Fix 2: overflow hidden */
.fix-overflow { overflow: hidden; }

/* Fix 3: clearfix pseudo-element (classic) */
.clearfix::after {
  content: ''; display: block; clear: both;
}

/* Best practice: only use float for text wrapping.
   Use Flexbox/Grid for column layouts! */
✏️ Your Task

Create a parent div with floated images inside. Notice it collapses. Add display: flow-root to the parent — the height is restored! Then try the clearfix: add .clearfix::after { content:''; display:block; clear:both; }.

starter.html — copy this into a new file!

      body { font-family: Georgia, serif; background: #f0f9ff; padding: 30px; max-width: 820px; margin: 0 auto; color: #0f172a; }

      .article-section { display: flow-root; margin-bottom: 24px; }
      .img-left  { float: left;  width: 220px; height: 150px; object-fit: cover; border-radius: 10px; margin: 0 20px 12px 0; }
