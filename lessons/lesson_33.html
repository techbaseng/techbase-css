CSS Dropdowns

Phase 1
Basic CSS Dropdown
💡 Concept

A CSS dropdown: the parent <li> is position: relative. The dropdown <ul> inside is position: absolute; display: none. On li:hover, set the nested ul to display: block. Add z-index to keep the menu above other content. The top: 100% positions it directly below the parent.

style.css 
/* Dropdown container */
.dropdown { position: relative; }

/* Hidden by default */
.dropdown-menu {
  display: none;
  position: absolute;
  top: 100%;
  left: 0;
  min-width: 200px;
  background: white;
  border: 1.5px solid #e2e8f0;
  border-radius: 10px;
  box-shadow: 0 8px 24px rgba(0,0,0,.12);
  z-index: 200;
  padding: 6px 0;
  margin-top: 4px;
}

/* Show on hover */
.dropdown:hover .dropdown-menu { display: block; }

/* Menu items */
.dropdown-menu a {
  display: block;
  padding: 10px 16px;
  color: #334155;
  text-decoration: none;
  font-size: 14px;
  transition: background .15s;
}
.dropdown-menu a:hover {
  background: #f0f9ff;
  color: #0284c7;
}

Phase 2
Animated Dropdowns and Click-toggle
💡 Concept

Improve the hover dropdown with CSS transitions: animate the dropdown sliding down from above using transform: scaleY(0) to transform: scaleY(1) with transform-origin: top. For accessibility, add click-to-toggle using a tiny JavaScript function rather than hover-only. Add a small arrow indicator with ::after.

style.css 
/* Animated dropdown */
.dropdown-menu {
  display: block;
  opacity: 0;
  transform: scaleY(0);
  transform-origin: top;
  transition: opacity .2s, transform .2s;
  pointer-events: none;
}

.dropdown:hover .dropdown-menu {
  opacity: 1;
  transform: scaleY(1);
  pointer-events: auto;
}

/* Arrow indicator */
.dropdown > a::after {
  content: ' ▾';
  font-size: .75em;
  opacity: .7;
}

/* Divider inside dropdown */
.dropdown-divider {
  height: 1px;
  background: #e2e8f0;
  margin: 6px 0;
}

/* Dropdown sections */
.dropdown-header {
  font-size: 11px;
  text-transform: uppercase;
  letter-spacing: .06em;
  color: #94a3b8;
  padding: 8px 16px 4px;
  font-weight: 700;
}
