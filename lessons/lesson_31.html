Phase 1
opacity vs rgba
💡 Concept

opacity: 0.5 makes an element (and ALL its children) 50% transparent. rgba(r,g,b,0.5) makes only the background colour transparent — the text inside stays fully opaque. This is a critical difference! Also: opacity: 0 hides but keeps space; visibility: hidden also keeps space; display: none removes entirely. CSS also has transparent as a colour keyword.

style.css 
/* opacity affects the WHOLE element including text */
.fade-50 { opacity: 0.5; }
.fade-25 { opacity: 0.25; }

/* rgba — only the background is transparent; text stays opaque */
.bg-rgba {
  background: rgba(2, 132, 199, 0.2);
  color: #0f172a; /* stays fully visible */
}

/* Hover reveal effect */
.card-img { opacity: 0.7; transition: opacity .3s; }
.card-img:hover { opacity: 1; }

/* Overlay with rgba */
.hero-overlay {
  background: linear-gradient(
    to bottom,
    rgba(0,0,0,0),
    rgba(0,0,0,0.7)
  );
}

/* Transparent keyword */
.ghost-btn {
  background: transparent;
  border: 2px solid #0284c7;
}

Phase 2
Opacity Transitions and Overlays
💡 Concept

Opacity + CSS transitions create elegant hover and reveal effects. An overlay is a common pattern: an absolutely positioned div with semi-transparent background that appears on hover to reveal text over an image. Opacity can also be animated with @keyframes for fade-in effects. pointer-events: none on an invisible element prevents it from blocking clicks.

style.css 
/* Hover image overlay */
.image-card { position: relative; overflow: hidden; border-radius: 12px; }
.image-card img { width: 100%; display: block; transition: transform .3s; }
.image-card:hover img { transform: scale(1.05); }
.image-card .overlay {
  position: absolute; inset: 0;
  background: rgba(2,132,199,0.85);
  display: flex; align-items: center; justify-content: center;
  opacity: 0; transition: opacity .3s;
}
.image-card:hover .overlay { opacity: 1; }
.image-card .overlay p { color: white; font-weight: bold; text-align: center; }

/* Fade-in animation */
@keyframes fadeIn {
  from { opacity: 0; transform: translateY(10px); }
  to   { opacity: 1; transform: translateY(0); }
}
.fade-in { animation: fadeIn .6s ease forwards; }
