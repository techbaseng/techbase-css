CSS Forms

Phase 1
Form Layout and Input Styling
💡 Concept

Key form CSS rules: Labels above inputs (not beside — better for mobile). width: 100% on inputs so they fill their container. Generous padding (12px 14px). Remove default outline with outline: none and replace with a custom focus shadow. Use border-radius for modern look. font-family: inherit on inputs — browsers don't inherit fonts automatically.

style.css 
/* Form container */
.form-card { background: white; border-radius: 18px; padding: 32px;
             max-width: 480px; box-shadow: 0 4px 20px rgba(0,0,0,.08); }

/* Field wrapper */
.field { margin-bottom: 20px; }

/* Labels */
label { display: block; font-weight: 700; font-size: 13px;
        color: #475569; margin-bottom: 6px; letter-spacing: .02em; }

/* Inputs */
input, select, textarea {
  width: 100%; padding: 12px 14px; font-size: 15px;
  border: 1.5px solid #e2e8f0; border-radius: 10px;
  font-family: inherit; background: #f8fafc; color: #0f172a;
  outline: none; transition: border-color .2s, box-shadow .2s;
}

input:focus, select:focus, textarea:focus {
  border-color: #0284c7;
  background: white;
  box-shadow: 0 0 0 3px rgba(2,132,199,.18);
}

/* Submit button */
.btn-submit { width: 100%; padding: 14px; background: #0284c7; color: white;
              border: none; border-radius: 10px; font-size: 16px;
              font-weight: 700; cursor: pointer; transition: background .2s; }
.btn-submit:hover { background: #0369a1; }

Phase 2
Validation States and Custom Checkboxes
💡 Concept

HTML5 validation pseudo-classes: :valid (green border), :invalid (red border). Only show invalid state after the user has touched the field — use the :not(:placeholder-shown) hack to detect touched inputs: input:not(:placeholder-shown):invalid. Custom checkboxes: hide the native input with appearance: none and draw your own with ::before.

style.css 
/* Smart validation — only show after user touches field */
input:not(:placeholder-shown):valid {
  border-color: #10b981;
}
input:not(:placeholder-shown):invalid {
  border-color: #ef4444;
}

/* Error message */
.error-msg {
  font-size: 12px; color: #ef4444; margin-top: 5px; display: none;
}
input:not(:placeholder-shown):invalid ~ .error-msg { display: block; }

/* Custom checkbox */
.custom-check { display: flex; align-items: center; gap: 10px; cursor: pointer; }
.custom-check input[type="checkbox"] {
  appearance: none; width: 20px; height: 20px;
  border: 2px solid #cbd5e1; border-radius: 6px;
  position: relative; cursor: pointer; transition: .15s;
  flex-shrink: 0; background: white; padding: 0;
}
.custom-check input:checked { background: #0284c7; border-color: #0284c7; }
.custom-check input:checked::before {
  content: ''; position: absolute; top: 3px; left: 6px;
  width: 5px; height: 9px;
  border-right: 2px solid white; border-bottom: 2px solid white;
  transform: rotate(45deg);
}
✏️ Your Task

Add smart validation to your email input: use input:not(:placeholder-shown):invalid { border-color: #ef4444; }. The red border only appears after the user types, not before they touch the field. Add a custom checkbox with appearance: none and a CSS checkmark.

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Forms</title>
    <style>
      *, *::before, *::after { box-sizing: border-box; }
      body { font-family: Arial, sans-serif; background: #f0f9ff; min-height: 100vh;
             display: flex; align-items: center; justify-content: center; padding: 24px; }
      .card { background: white; border-radius: 20px; padding: 36px;
              width: 100%; max-width: 480px; box-shadow: 0 8px 32px rgba(0,0,0,.1); }
      .card h1 { color: #0284c7; font-size: 1.6rem; margin: 0 0 4px; }
      .card .sub { color: #64748b; font-size: 13px; margin: 0 0 28px; }
      .field { margin-bottom: 18px; }
      .row   { display: flex; gap: 14px; }
      .row .field { flex: 1; }
      label { display: block; font-weight: 700; font-size: 13px; color: #475569; margin-bottom: 5px; }
      input, select, textarea {
        width: 100%; padding: 12px 14px; font-size: 14px;
        border: 1.5px solid #e2e8f0; border-radius: 10px;
        font-family: inherit; background: #f8fafc; color: #0f172a;
        outline: none; transition: border-color .2s, box-shadow .2s;
      }
      input:focus, select:focus, textarea:focus { border-color: #0284c7; background: white; box-shadow: 0 0 0 3px rgba(2,132,199,.18); }
      input:not(:placeholder-shown):valid { border-color: #10b981; }
      input:not(:placeholder-shown):invalid { border-color: #ef4444; }
      .hint { font-size: 11px; color: #94a3b8; margin-top: 4px; }
      .custom-check { display: flex; align-items: center; gap: 10px; cursor: pointer; margin-bottom: 14px; }
      .custom-check span { font-size: 13px; color: #475569; line-height: 1.4; }
      .custom-check input[type="checkbox"] { appearance: none; width: 20px; height: 20px; border: 2px solid #cbd5e1; border-radius: 6px; position: relative; cursor: pointer; transition: .15s; flex-shrink: 0; background: white; padding: 0; margin: 0; }
      .custom-check input:checked { background: #0284c7; border-color: #0284c7; }
      .custom-check input:checked::before { content: ''; position: absolute; top: 3px; left: 6px; width: 5px; height: 9px; border-right: 2px solid white; border-bottom: 2px solid white; transform: rotate(45deg); }
      .btn { width: 100%; padding: 14px; background: #0284c7; color: white; border: none; border-radius: 10px; font-size: 15px; font-weight: 700; cursor: pointer; transition: background .2s; margin-top: 4px; }
      .btn:hover { background: #0369a1; }
      .divider { text-align: center; color: #94a3b8; font-size: 13px; margin: 18px 0; position: relative; }
      .divider::before, .divider::after { content: ''; position: absolute; top: 50%; width: 42%; height: 1px; background: #e2e8f0; }
      .divider::before { left: 0; } .divider::after { right: 0; }
    </style>
  </head>
  <body>
    <div class="card">
      <h1>Create Account</h1>
      <p class="sub">Join Techbase Academy — it's free!</p>
      <form>
        <div class="row">
          <div class="field"><label for="fn">First Name *</label>
            <input id="fn" type="text" required minlength="2" placeholder="Tunde"></div>
          <div class="field"><label for="ln">Last Name *</label>
            <input id="ln" type="text" required minlength="2" placeholder="Awoyemi"></div>
        </div>
        <div class="field"><label for="em">Email *</label>
          <input id="em" type="email" required placeholder="you@example.com">
          <p class="hint">Enter a valid email — border turns green ✓</p>
        </div>
        <div class="field"><label for="pw">Password (min 8 chars) *</label>
          <input id="pw" type="password" required minlength="8" placeholder="••••••••">
        </div>
        <div class="field"><label for="course">Course Interest</label>
          <select id="course">
            <option value="">— Choose a course —</option>
            <option>HTML Basics</option>
            <option>CSS Mastery</option>
            <option>JavaScript</option>
            <option>Python</option>
          </select>
        </div>
        <label class="custom-check">
          <input type="checkbox" required>
          <span>I agree to the <a href="#" style="color:#0284c7">Terms of Service</a> and <a href="#" style="color:#0284c7">Privacy Policy</a></span>

          <input type="checkbox">
          <span>Send me updates about new courses and features</span>

        <button type="submit" class="btn">Create Free Account →</button>
