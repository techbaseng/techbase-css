Phase 1
Element, Class and ID Selectors
💡 Concept

The three most common selectors: Element selector — targets all elements of that type: p { color: blue; }. Class selector — targets elements with that class (reusable): .highlight { background: yellow; }. ID selector — targets ONE unique element: #header { height: 60px; }. Rule: element is broadest, class is the everyday tool, ID is most specific and should be used sparingly.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Selectors</title>
    <style>
      /* Element selector — targets ALL paragraphs */
      p { color: #334155; line-height: 1.7; }

      /* Class selector — reusable on many elements */
      .highlight { background: #fef3c7; padding: 4px 8px; border-radius: 4px; }
      .danger    { color: #dc2626; font-weight: bold; }
      .success   { color: #16a34a; font-weight: bold; }

      /* ID selector — one unique element */
      #main-title {
        color: #0284c7;
        font-size: 2rem;
        border-bottom: 3px solid #0284c7;
        padding-bottom: 8px;
      }
    </style>
  </head>
  <body>
    <h1 id="main-title">Selector Examples</h1>
    <p>This paragraph uses the <span class="highlight">element selector</span>.</p>
    <p>This word is <span class="danger">dangerous</span>!</p>
    <p>This word is <span class="success">successful</span>!</p>
    <div class="highlight">This whole div is highlighted with the class selector.</div>
  </body>
</html>

Phase 2
Universal, Grouping and Descendant Selectors
💡 Concept

More powerful selectors: Universal * targets every element (used in * { box-sizing: border-box; }). Grouping h1, h2, h3 applies the same rules to multiple selectors at once. Descendant div p targets only paragraphs that are INSIDE a div. Child div > p targets only DIRECT children. Adjacent h1 + p targets the first paragraph immediately after an h1.

style.css 
/* Universal — applies to EVERYTHING */
* { box-sizing: border-box; margin: 0; padding: 0; }

/* Grouping — same rules for h1, h2, h3 */
h1, h2, h3 {
  font-family: Arial, sans-serif;
  color: #0f172a;
}

/* Descendant — only <a> tags inside nav */
nav a {
  color: white;
  text-decoration: none;
}

/* Child selector — direct children only */
.card > h3 {
  color: #0284c7;
  margin-top: 0;
}

/* Adjacent sibling — first <p> after each <h2> */
h2 + p {
  font-size: 1.1rem;
  font-weight: 600;
  color: #0284c7;
}

Phase 3
Attribute and Pseudo-class Selectors
💡 Concept

Attribute selectors target elements based on their attributes: a[target='_blank'] (links that open in a new tab), input[type='email'] (email inputs). Pseudo-classes style elements in a specific STATE: a:hover (mouse over), a:visited (already clicked), li:first-child (first item in a list), p:last-child, tr:nth-child(even) (every other row).

style.css 
/* Attribute selector */
a[target="_blank"] { color: #7c3aed; }
a[target="_blank"]::after { content: " ↗"; }

input[type="email"]  { border-color: #0284c7; }
input[type="submit"] { background: #0284c7; color: white; }

/* Pseudo-classes */
a:hover  { text-decoration: underline; color: #0369a1; }
a:visited { color: #7c3aed; }

li:first-child { font-weight: bold; color: #0284c7; }
li:last-child  { color: #94a3b8; font-style: italic; }

tr:nth-child(even) { background: #f0f9ff; }
tr:nth-child(odd)  { background: white; }

/* Focus state — accessibility! */
input:focus { outline: 2px solid #0284c7; outline-offset: 2px; }

🏗️ Build It!
My Selector Showcase

Build a page demonstrating every selector type — element, class, id, descendant, pseudo-class.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Selectors Showcase</title>
    <style>
      /* Universal reset */
      * { box-sizing: border-box; margin: 0; padding: 0; }

      /* Element selectors */
      body { font-family: Arial, sans-serif; background: #f0f9ff;
             color: #0f172a; padding: 30px; }
      h1   { color: #0284c7; margin-bottom: 6px; font-size: 2rem; }
      h2   { color: #0369a1; margin: 28px 0 14px;
             border-bottom: 2px solid #bae6fd; padding-bottom: 6px; }
      p    { color: #334155; line-height: 1.7; margin-bottom: 10px; }

      /* Class selectors */
      .card { background: white; border-radius: 12px; padding: 20px;
              border: 1.5px solid #e2e8f0; margin-bottom: 16px; }
      .card.featured { border-color: #0284c7;
                       box-shadow: 0 4px 12px rgba(2,132,199,.15); }
      .badge { display: inline-block; padding: 2px 10px; border-radius: 100px;
               font-size: 12px; font-weight: bold; }
      .badge-blue  { background: #dbeafe; color: #1e40af; }
      .badge-green { background: #dcfce7; color: #166534; }

      /* ID selector */
      #hero { background: linear-gradient(135deg, #e0f2fe, #f0f9ff);
              border-radius: 16px; padding: 32px; margin-bottom: 28px; }

      /* Descendant selectors */
      .card > h3       { color: #0284c7; margin: 0 0 8px; }
      .card > p        { color: #475569; font-size: 14px; margin: 0; }

      /* Grouping */
      h1, h2, h3       { font-family: Arial, sans-serif; font-weight: 700; }

      /* Pseudo-classes */
      a                { color: #0284c7; text-decoration: none; font-weight: 600; }
      a:hover          { text-decoration: underline; color: #0369a1; }
      a:visited        { color: #7c3aed; }
      a[target="_blank"]::after { content: " ↗"; font-size: 11px; }

      li               { padding: 8px 0; border-bottom: 1px solid #e2e8f0; }
      li:first-child   { font-weight: bold; color: #0284c7; }
      li:last-child    { border-bottom: none; color: #94a3b8; font-style: italic; }

      /* Attribute selector */
      input[type="text"] { width: 100%; padding: 10px; border: 1.5px solid #bae6fd;
                           border-radius: 8px; font-size: 14px; }
      input[type="text"]:focus { outline: 2px solid #0284c7; border-color: #0284c7; }
    </style>
  </head>
  <body>

    <div id="hero">
      <h1>CSS Selectors Showcase</h1>
      <p>This page demonstrates every major CSS selector type.</p>
    </div>

    <h2>Class Selectors — Cards</h2>
    <div class="card">
      <h3>Normal Card</h3>
      <p>Styled with <code>.card</code> class selector.</p>
      <span class="badge badge-blue">Basic</span>
    </div>
    <div class="card featured">
      <h3>Featured Card</h3>
      <p>Uses both <code>.card</code> AND <code>.featured</code> classes.</p>
      <span class="badge badge-green">Featured</span>
    </div>

    <h2>Pseudo-class Selectors — List</h2>
    <ul style="list-style:none; background:white; border-radius:12px;
               padding:0 20px; border:1.5px solid #e2e8f0;">
      <li>First item — bold blue (li:first-child)</li>
      <li>Second item — normal style</li>
      <li>Third item — normal style</li>
      <li>Last item — grey italic (li:last-child)</li>
    </ul>

    <h2>Attribute Selector — Links</h2>
    <p>
      <a href="#internal">Internal link (no ↗)</a> &nbsp;|&nbsp;
      <a href="https://techbasengr.com.ng" target="_blank">External link (gets ↗)</a>
    </p>

    <h2>Input Focus State</h2>
    <input type="text" placeholder="Click here — blue focus ring appears">

  </body>
</html>
